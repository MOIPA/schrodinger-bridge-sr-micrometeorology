## 1. 降尺度跨度扩展选项

```
从粗往细:27km(d01) → 9km(d02) → 3km(d03) → 1km(d04) → 111m(LES) → 37m(LES)
跨度:       27×          9×        3×(现役)      9×           3×
```

| 方案 | 低精度源 | 跨度 | 样本量 | 可行性与约束 |
|:---:|:---:|:---:|:---:|------|
| **A** | d02 9 km | 9× | 744×2 方案 = 1488(小时级,与 d03 对齐方式相同) | **推荐首选**:d02 覆盖 d04 区域余量极大;流程与 d03 完全同构,改源域即可 |
| B | d02 + d03 | 9× vs 3× | 各 1488 | 研究"跨度大小对超分难度/收益的影响";流程复用 A |
| C | d01 27 km | 27× | 744×2 | 极限跨度参照;信息损失可能过大,作上限对照 |
| D | LES 111 m(往更细) | 1km→111m(9×) | 与 d04 对齐后 **≈157 个** | 约束多:LES 仅覆盖 28×28 km(d04 域内一小块)、仅 ≈26 小时(2020-07-13 一天多);面向城市街区尺度 |
| E | LES 37 m | 111m→37m 或 1km→37m | ≈157 | 覆盖仅 10×10 km,更受限 |

**建议顺序**:先 A(改动小、样本多、面向预报模式输出,业务实用)→ 再 D(百米级、面向城市风场)→ C/E 作扩展。

## 2. 实施要点

1. **重采样**:与 `scripts/prepare_wind_data_3d_sz_d03.py` 同法——按 XLAT/XLONG 用 scipy griddata 把源域场重采样到 d04 的 (99,120) 网格(即"低精度场重采样到高精度网格"约定)
2. **层对齐**:源域同为 61 层,取相同 eta 索引(0,1,2,3,5,10)
3. **条件变量**:同时制备源域(3km/9km)与 d04(1km)两个版本,支持全低精度实验
4. **时间对齐**:d02/d03 小时级 ⊂ d04 的 10-min 时次,时间戳精确到秒配对;LES 为 1-min,按 10-min 取整对齐
5. **统计量**:每个新数据集独立计算 bias/scale,勿与既有数据集混用
6. **命名**:沿用 `{scheme}_{YYYYMMDDTHHMMSS}.npz`(scheme 前缀区分 myj/ysu);输出目录按数据源命名(如 `prepare_npz_wind_3d_sz_d02/`)
7. **评估口径**:与 `scripts/evaluate_sz_experiments.py` 一致(同划分逻辑、同指标函数);新跨度实验与 3× 现役结果对比时注明低精度源

## 3. 边界与已知问题

- 官方 train/valid/test 按文件名排序切分,myj 全在训练段、测试段全为 ysu(A5 已核实);新数据集沿用前注意切分口径
- case02 时间戳格式与 case01 可能不同(1970 年起算?),预处理前先 inspect
- LES 无中间分辨率配对(d04 与 LES 之间跳 9×),级联方案需把 d04 当作中间级
