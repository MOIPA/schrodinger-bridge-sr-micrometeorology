# 面向大气导师的汇报写作规范(advisor-report)

## 0. 读者画像与总体原则

- 读者是大气科学导师,非深度学习背景:物理概念(模式、PBL、嵌套域、气压层)可默认懂,ML/CS 概念必须用中文解释或换说法
- 总体风格:**正式学术书面语 + 专业术语正常使用 + 关键概念自然解释**,绝不是"大白话重写",也不是术语堆砌
- 视角是汇报人第一人称"我/我们",内容只陈述自己的工作与判断,**绝不臆测导师意图**(不要写"导师发这篇是为了敲打我""老师想看的是…")
- 保持黑盒视角:模型对外只讲输入输出与精度来源,不展开内部机制(如中间态、框架数学细节),除非专门讨论方法
- 数字必须与底账 `docs/深圳实验成果记录.md` 与评估 JSON 一致;改动数字前先核对源文件

## 1. 语言规范

1. 正式书面语,禁口语、禁比喻式"通俗化":不用"什么都不学、底线、尺子、本钱、真东西、要命、换皮、凑数、白用、背"等
2. 英文术语如 baseline、RMSE、MAE、SSIM 直接正常使用,不要强行翻译或加引号
3. 必要缩写首次出现给出中文全称或一句解释,如 2 m 气温、行星边界层高度;垂直层 ml0~ml10 首次给出"近地面到约 300 m 共六层"这类高度信息(高度等事实性数字必须核实,勿沿用未经验证的说法)
4. 单位与量级统一用 km、m、m/s,不用"公里"
5. 不堆括号:补充说明优先写成从句或单独句子;引号基本不用,强调用加粗

## 2. 术语中文化对照表(出现英文黑话先查此表)

| 黑话 | 正文写法 |
|---|---|
| 时次 | 时刻 |
| epoch / epochs | 轮 / 训练 300 轮 |
| loss | 误差(或损失,须配解释) |
| checkpoint | 模型(如"训练 300 轮的最终模型""中途模型") |
| HR 条件 / LR 条件 | 1km 条件 / 3km 条件 |
| test 集 | 测试集 |
| div / vort 权重 | 散度权重 / 涡度权重 |
| 模拟退化 / 真实退化 | 模拟低精度 / 真实低精度(数据来源,不用"退化"黑话) |
| 平均池化 | 格点平均(4×4 格点平均) |
| 时次对齐 / 匹配 | 同一时刻配对(时间戳精确到秒) |
| 上下采样 / 插值放大 | 上采样可直说"插值放大"或保留术语,首次给解释 |

术语表:若正文必然出现 loss/epoch 等,在 2.5 节式术语表中集中解释(表格:术语 | 含义),正文其余位置不用。

## 3. 负面清单(一眼 AI 的写法 → 正式写法)

| 不要(口语/比喻) | 要(正式) |
|---|---|
| 先算"什么都不学"的底线 | 计算不学习的插值 baseline,作为所有学习模型的性能下界 |
| 用多把尺子量结果 | 建立多维度评价体系 |
| 数据条件是我们最大的本钱 | 数据条件具有独特性 |
| 学到的是真东西 | 学到的是有效的超分映射 |
| 把高分辨率自己抹粗凑数 | 对高分辨率场人为粗化 |
| 概率价值还没兑现 | 扩散模型的概率能力尚未利用 |
| 强风/小尺度最要命 | 按风速强度分箱考察误差分布、以能谱检查小尺度结构 |
| 这正好/恰好/说白了/其实就是 | 直接陈述事实或判断 |

自查方法:写完通读一遍,把任何"日常对话里会说的话"改书面语;把任何一处感觉在"讨好读者"的通俗化处理删掉重写。

## 4. 结构与内容要点

1. 背景叙事用真实动机:从香港到深圳(数据条件变化、为什么做),不写八股式研究意义
2. 方法与数据节必须讲清:模型输入输出是什么、各是什么精度、数据哪里来;预处理工作量要体现(多少文件、时间间隔、配对方式、统计归一化)
3. 结果表后直接写无标签的结论段（用户 2026-09-11 手改时删除了所有"读法:"引用块与"解读:"标签——不要用这两种格式）
4. 结果给绝对参照:模型误差相对插值基线、相对随机猜测(RMSE=1)的位置,不只做模型间相对比较
5. 物理约束等专业内容配含义表(表达式 | 含义 | 权重)
6. 下一步计划用 `**项名**：一句话` 一行一项列出，不写排期、不写"恳请老师提出意见"
7. 未完成的实验只在"下一步"以一行列出,不放进结果部分
8. 结果项统一按以下版式组织:

```
**A1 能量谱诊断**

该步骤参考了论文:Mardani 等(2025,CorrDiff)、Dettling 等(2025)。

对模型预测场、1 km 真值与插值结果分别计算径向平均功率谱,检验细节还原程度。

结果:高波数段谱功率与真值的比值,1.0 表示完全一致

(数据表)

(无标签结论段:一句话结论 + 一句意义)
```

要点:出处句 → 做法一句 → "结果:"直出数据 → 无标签结论段。用户的最终版比此前的 skill 规范更短:删掉了读法块、解读标签、分组代号、排期与文末备注，全篇只保留标题、正文、表格、图。

## 5. 排版格式规范

1. 不用特殊符号:§、⭐ 等一律不用;重点文献/模型用**加粗**并在附近说明
2. 标题编号用"一、二、三"与"1. 2. 3.";小节标题中文
3. 表格一律有表头;表格后接无标签结论段（不用引用块）
4. 图与 md 同目录,markdown 相对路径引用,图题写清内容
5. 零装饰:不写日期注、不写数字来源注、不写排期——用户最终版删除了这些

## 6. 文件与工作流

- 组会汇报存放:组会汇报/YYYY-MM-DD/组会汇报-标题.md,配图同目录
- 实验跑批脚本:ops/queue/NN_*.sh(自带 git 自动回传);手机执行 bash ops/queue/NN_*.sh
- 报告数字一律从 docs/深圳实验成果记录.md 与 results/*_metrics.json 抄录或核对
- 命名对照:lrcond=allLR、pinn=phys;后缀 -d03=训练数据为真实 d03;区分"评估数据 d03"(跨域)
- 完成后 git commit + push 自动同步
- 相关 skill:实验设计见 sr-exp-design;论文摘要见 docs/论文总结

- [ ] 每张表后有**无标签**结论段（不是"读法:"引用块）
- [ ] 输入输出、精度（含地形等条件变量精度）、低精度数据来源（模拟/真实）讲清
- [ ] 每个结果项注明用的哪个模型
- [ ] 第一人称、不臆测导师意图
