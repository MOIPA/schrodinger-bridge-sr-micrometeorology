# 术语词典(概念解释与命名对照)

## 1. 模型与训练

| 术语 | 解释 |
|------|------|
| Stochastic Interpolant(SI) | 生成模型框架:把"低分辨率→高分辨率"的变换建模为沿插值路径的连续输运,模型学的是路径上的速度场。比经典扩散模型(高斯噪声起点)更直接 |
| 漂移场 b | 模型每一步的输出(18 通道),指示"当前风场往哪个方向修正"的修正方向场;物理约束施加在它上面,而非最终风场 |
| y0 | 低分辨率风场(模型输入的起点) |
| y_cond | 条件输入张量(26 通道:18 LR 风场 + 8 条件变量的拼接);代码里 `sample_y1_bare_diffusion(y0=y0, y_cond=x)` |
| 渐进重建 | 推理时从 y0 出发、分 10 步(可配 n_timestep)逐步细化到 1 km,不是一步出结果 |
| checkpoint / 最终模型 | 训练过程保存的模型快照;"300 轮最终模型"= 训练结束时保存的(注意:物理约束模型的最佳状态可能在中途) |

## 2. 物理约束

| 项 | 含义 | 在本项目中 |
|----|------|-----------|
| 散度 ∇·b = 0 | 质量守恒(不可压近似):流体不会凭空在某点聚集或消失 | 对漂移场 b 的中心差分,权重 0.1 |
| 涡度 ζ(b) = 0 | 不引入虚假旋转;真实流动的涡度来自物理过程,不应由模型噪声制造 | 仅约束**大尺度分量**(avg_pool k=4 后),权重 0.05,避免压制真实小尺度涡 |
| 为什么施加在漂移场 b 上 | b 是模型生成的"修正方向",约束它等于约束生成过程的物理性;且 b 与最终风场同形状,计算方便 | 香港/深圳所有 phys 类模型 |
| NS 动量方程(未做) | 完整动力学约束(平流、气压梯度力、科氏力、湍流扩散);深圳数据变量齐全,可行 | 下一步 C 组方向 |

## 3. 大气概念(给非大气背景)

| 术语 | 解释 |
|------|------|
| eta 层 / eta 模式层 | WRF 的垂直坐标层(地形追随);本项目取 ml0/ml1/ml2/ml3/ml5/ml10 六层,约 10 m 到 300 m(近地面密) |
| U / V / W | U = 东西向风(西风为正),V = 南北向风(南风为正),W = 垂直风(上升为正);W 比 U/V 小 1-2 个数量级、最难预测 |
| PBLH | 行星边界层高度:湍流混合层的顶高,白天高(对流)、夜间低(稳定) |
| 感热/潜热通量(HFX/LH) | 地表与大气间的热量/水汽交换,热力驱动的表征 |
| swdown | 下行短波辐射;本项目用太阳高度角合成(深圳模拟无辐射输出),仅用于昼夜划分(白天>50,夜间<5 W/m²) |
| 地形追随坐标 | WRF 的垂直坐标随地形起伏,笛卡尔差分在山区附近失真——完整 NS 约束要用 PH/PHB 高度做变换 |
| PBL 方案 MYJ / YSU | 两套边界层参数化:MYJ 局地闭合(TKE),夜间稳定层好;YSU 非局地,白天对流好。同一时段的两个"物理版本"模拟,数据量相同 |

## 4. 术语对照(说得清来源)

| 我们的说法 | 领域对应说法 |
|------|------|
| 条件变量(8 个:t2, z, lu, tsk, hfx, lh, psfc, pblh) | 生成模型的 conditional inputs / 统计降尺度的**预测因子(predictors)/协变量(covariates)**;指不参与超分、只提供物理上下文的辅助输入(为何叫条件变量:生成模型求 p(HR \| 附加信息),这些是"条件") |
| 模拟低精度 | 完美降采样:1 km 真值经 4×4 格点平均降到 3 km 再插值放大回 1 km(与目标逐点对齐) |
| 真实低精度 | WRF 原生输出的粗网格场(如 d03 的 3 km)重采样到 1 km 网格 |
| 降尺度 / 超分 | 大气领域叫"降尺度"(downscaling),深度学习领域叫"超分辨率"(SR);本项目两者同义 |

## 5. 实验命名对照

| 报告显示名 | 技术名(配置/checkpoint) | 含义 |
|:---:|:---:|------|
| baseline | baseline | 标准输入:1 km 条件、无物理约束 |
| allLR | **lrcond** | 全低精度输入:条件变量(含地形)3 km |
| phys | **pinn** | 运动学约束(散度+涡度) |
| allLR+phys | **lrcond_pinn** | 全低精度 + 物理约束 |
| 后缀 **-d03** | 同前 | 训练数据为真实低精度 d03(如 phys-d03 = 在 d03 上训练的物理约束模型) |

注意:"跨域评估"里的 d03 指**评估数据**,与后缀 -d03 的"训练数据"含义不同。

## 6. 指标口径

- 全部在**标准化空间**评估:逐变量减均值除标准差(各自训练集统计量),数值无量纲,1.0 ≈ 随机猜测
- RMSE/MAE 越小越好;SSIM(空间结构相似度)0-1 越大越好;Corr 越大越好;bias = 预测均值−真值均值,正=整体高估
- 插值基线作为性能下界:模型误差相对它的降幅是主要汇报口径(如 baseline 比插值低 52%)
