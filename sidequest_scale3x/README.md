# 外传 · 三尺度 3× 放大对比

> 本目录**不属于导师大纲的任何阶段**,是老师 2026-10-31 口头追加的一条支线。
> 报告、结果、代码全部独立存放,不写进 `docs/阶段报告/`,也不占阶段编号。

## 一句话

问:**同样"放大 3 倍",在 27 km→9 km、9 km→3 km、3 km→1 km 三个起始尺度上,学到的算子是不是同一回事?**
老师说"每个阶段的灰度区间不一样",这句话要么被证实(三个算子必须分开训),要么被量化修正(差多少、差在哪)。

## 为什么这三段可比

WRF 嵌套是 3 倍降尺度:d01 27 km → d02 9 km → d03 3 km → d04 1 km。
所以三段的**放大倍数完全相同(3×)**,只有起始分辨率不同。这构成一张干净的对照实验:
固定 ratio,只变 base scale。

(注意:这与阶段 4 的 27→1、3→1 不同——那两个是 9× 与 3×,回答的是"极限跨度能不能一步跨过去"。
本支线回答的是"算子随尺度怎么变"。两者互为补充,不重复。)

## 实验设计

| 组 | 输入 → 输出 | 角色 |
|---|---|---|
| A | d01 (27 km) → d02 (9 km) | 最平滑、"灰度区间"最窄 |
| B | d02 (9 km) → d03 (3 km) | 中间尺度 |
| C | d03 (3 km) → d04 (1 km) | 与阶段 3 同域同尺度,但输入换成 3 km 而非 9 km |

每组都要:

1. **训练**一个同架构模型(与阶段 3 的 reg 基座同超参,只改三行数据路径)——保证"架构差异"不是混杂因素;
2. **两个插值基线**:bilinear、bicubic(同一批测试样本、同一指标);
3. **同一个评估口径**:AGL 目标层、矢量 RMSE、风速偏差、风向误差、切变误差——全部沿用阶段 3 的 `99_*` 脚本口径,便于横向读。

## 老师说的"灰度区间"怎么量化

不靠形容词,给四个数(脚本 `scripts/gap_stats.py`):

| 量 | 含义 | 预期方向 |
|---|---|---|
| σ_fine / σ_coarse | 细节能长多少 | 27→9 最小,3→1 最大 |
| R² = 1 − var(res)/var(fine) | 粗端能解释细端的比例 | 尺度越细,粗端解释率越低 |
| 残差 σ 与峰度 | 残差分布宽度与尖峰程度 | 极值随尺度变尖 |
| 功率谱斜率 β | 场的空间粗糙度(S(f) ∝ f^(−β)) | 27 km 场更陡(更光滑) |

这四个数量化"灰度区间",再和三个模型的"相对插值增益"对上,就能回答老师:
**增益是不是随区间变宽而变大?哪个尺度的映射最难学?**
