# 外传-1b · 用**真粗端**重做"缺口"量化

> 独立支线,不属于导师大纲阶段编号。替代 `外传-1` 里的 3×3 块平均代理口径。
> 脚本 `sidequest_scale3x/scripts/gap_real.py`(量化)+ `ops/debug/gap_check.py`(配准核查);
> 结果 `sidequest_scale3x/results/gap_real.json`。数据:2020-07 wrfout,myj 方案,项目自建 npz。

## 0 一句话

换成真粗端以后,三段缺口(粗端解释不了的那部分方差占比)是 **27→9 = 2.6% / 9→3 = 20.4% / 3→1 = 15.8%**,跨度 27→1 一档是 **55.7%**;这与 `外传-1` 的块平均代理(4.3% / 7.7% / 10.4%)**排序不同、量级差 2–3 倍**,所以"缺口越大、相对增益越小"那条斜率(−1.8 pp / 1% 缺口)**作废**。能站住的替代说法是:**相对增益跟的是插值基线的绝对误差**(1.0232 / 0.7902 / 0.6152 m/s ↔ 39.5% / 35.8% / 28.6%),不是方差缺口比例。

## 1 为什么必须重做

`外传-1` 用的是"把细端自己 3×3 块平均、再最近邻放大"当粗端。这个代理有两个假设:

1. **块平均 ≈ 真粗端看到的场**。真粗端是 WRF 自己在 27/9/3 km 上积分的另一个解,它有自己的物理参数化、自己的边界强迫,并不是细端的空间低通;
2. **最近邻放大 ≈ 项目实际用的重网格**。项目用的是 `10_extract_statics.py` 建的双线性/面积权重,放大后是平滑场,不是马赛克。

两条都不成立时,算出来的"缺口"只能说明"块平均丢掉多少",不能说明"模型要长多少"。真粗端文件早就在服务器上(`prepare_npz_outline_coarse_d01` / `coarse` = d02 / `coarse_d03`),没有理由不直接用。

## 2 方法(每个数字的表达式)

对每一对(粗端域 → 细端域):

- **F** = 细端风速 `sqrt(f_u² + f_v²)`(destagger 到质量点);
- **C_up** = 真粗端 `c_u/c_v` 经 `CanvasStatics.regrid_field(..., 'u'/'v')`(项目自己的重网格权重)搬到细端网格,再 destagger;
- **R = F − C_up**;
- 对每个 **(时次, 层)** 各自在**水平空间上**算 `var(F)`、`var(R)`、`var(C_up)`,再对样本**等权**汇总:
  - `R² = 1 − Σvar(R) / Σvar(F)`
  - `缺口方差占比 = Σvar(R) / Σvar(F)`(= 1 − R²)
  - `σ细/σ粗 = Σstd(F) / Σstd(C_up)`
  - `残差RMSE = sqrt( mean( mean_space(R²) ) )`,`偏差 = mean( mean_space(R) )`
  - `峰度 = mean( 四阶标准化矩 )`
- 样本:细端与粗端文件名时次取交集后等间隔抽 6 个时次 × 最低 23 个模式层 = 138 个(时次,层)样本。

> **不能摊平算**(第一版就是栽在这里):不同层的平均风速差一倍,把 (时次×23 层) 摊平后 `var(F)` 主要由**垂直切变**贡献,会把 R² 系统性抬高——3→1 因此算出 0.983 的假高分,比 9→3 还"容易",与逐层相关(0.74–0.88)直接冲突。

## 5 三个发现

### 5.1 代理口径 vs 真粗端口径

| 尺度段 | 代理 `外传-1` | 真粗端 `外传-1b` | 差 |
|---|---|---|---|
| 27→9 | 0.958 | 0.974 | 代理**低估**了解释率(高估缺口) |
| 9→3 | 0.927 | **0.796** | 代理**高估**解释率 ~13 个点 |
| 3→1 | 0.887 | 0.842 | 代理高估 ~4.5 个点 |

代理并不是"一律偏保守":它把 9→3 想得太容易、把 27→9 想得太难。原因大概是:块平均只丢高频,而真粗端与细端之间还差**动力一致性**(不同域各自积分,位置/相位都不一样),9→3 这一档尤其明显。

### 5.2 9→3 是"最不像"的一档,而且有未解释的系统偏差

9→3 的 R² 最低(0.796)、残差偏差 **+0.316 m/s**(真粗端比细端整体偏强),其余三档偏差都在 ±0.12 内。这一条目前**没有解释**,只能记录:若后续要用"9 km 粗端 → 3 km"的设定做实验,必须知道这一档多了一层"整体偏强"的系统差,模型容易学到"减去 0.3 m/s"这种假规律。

### 5.3 方差解释率 ≠ 误差大小(所以斜率作废)

27→9 的 R² 高达 0.974,残差 RMSE 却有 0.671 m/s;原因很朴素:D02 域(150×180 格点、跨千余公里)的 `var(F)` 极大,3% 的残余方差落到绝对尺度上依然很大。反过来说,**相对插值增益**跟的是插值基线的绝对误差:

| 尺度段 | 插值基线 y0 RMSE | 相对插值增益 | 真粗端缺口方差占比 |
|---|---|---|---|
| 27→9 | 1.0232 | +39.5% | 2.6% |
| 9→3 | 0.7902 | +35.8% | 20.4% |
| 3→1 | 0.6152 | +28.6% | 15.8% |

左两列单调,**与缺口方差占比不成单调关系**。所以:

- ❌ 不能说"缺口的方差占比每涨 1%,相对增益掉 1.8 个百分点"(基于作废的代理数拟合);
- ✅ 能说"相对增益与插值基线的绝对误差同向",而且这是**基线误差越大、相对改进的余地越大**这个平凡但真实的机制;
- ⚠️ 三行数字本身仍建立在**统一划分后的重训模型**上(见 `外传-3` 顶部的作废横幅),此处引用前请确认那一轮重训已出结果。

## 6 能下与不能下

**能下**

1. 真粗端口径下,四个尺度对的缺口是 2.6% / 20.4% / 15.8% / 55.7%,与块平均代理不同;
2. 27→9 的缺口集中在近地层、随高度消失;9→3 与 3→1 整层均匀;27→1 中层最糟;
3. 三个 3× 段的残差都是**重尾**(峰度 9.6–14.2,高斯 = 0),即缺口不是高斯噪声;
4. 重网格配准正确(下一节)。

**不能下**

1. 只有 **6 个时次 × 23 个模式层**,且是**整月等间隔抽样**,不是 test 期,也不是 AGL 层;换样本数值会动,排序大概不变但不要报小数点后第三位;
2. 9→3 的 +0.316 偏差**没有解释**,不许当成"物理事实"引用;
3. R² 是**方差解释率**,不能换算成"模型能提升多少"(两者关系见 §5.3);
4. 27→1 那一档是阶段 4 的设定,它的 55.7% 缺口只能说明"跨 9 倍很难",不能直接预测阶段 4 模型的 RMSE。

## 7 工程记录(两次踩坑)

1. **摊平多层 → 假高分**:第一版把 (时次×层) 摊平算 `1 − var(R)/var(F)`,得 0.977 / 0.929 / **0.983** / 0.945。3→1 反而最容易,反直觉;与 `ops/debug/gap_check.py` 的逐层相关(0.74–0.88)冲突。改为逐 (时次,层) 空间方差再等权汇总。
2. **配准核查**:担心重网格把粗端映射错位会让 R² 虚高,于是把 `C_up` 循环平移 (1,0)(0,1)(3,0)(0,3)(5,5)(10,10) 格再算相关。实测最低层:27→9 0.980→(0.58–0.95)、9→3 0.93→(0.36–0.91)、3→1 0.88→(0.28–0.86)、27→1 0.62→(0.28–0.72),**平移一律让相关下降**,说明零平移处就是真配准位置,不是错位造成的假高。

- **真粗端 npz**(`prepare_npz_outline_coarse_d01` / `coarse` / `coarse_d03`):由 wrfout 抽取,属项目自建中间产物,非老师提供的"粗端数据文件";
