# 阶段 1 报告:9 km → 1 km 输入变量消融

对应大纲 T1.1–T1.7。固定条件 **UNet + L1 + 模式层监督**,开发档 **9 km(d02)→ 1 km(d04)**,
方案 myj、23 层(0..22)、划分与评估协议见检查点 A(`docs/大纲阶段0_协议冻结.md`)。
产出:**最优输入集 V\*** 与带显著性检验的边际贡献排序。

> **事后勘误(2026-10-03,阶段 2 发现;本文档数字不改)**:本阶段的训练配方存在**间歇性崩塌**——约半数轨迹在
> 训练早期某轮阶跃跳到 0.27~0.30 平台(与输入组/物理项无关,同配置换 seed 即可复现);该现象**可自行恢复但 patience=40
> 会在恢复前早停**(详见 `docs/阶段报告/阶段2_损失函数与物理约束.md` §五)。复查训练日志后,第二轮以下 run 属
> "早停受害者":**t14_cos(best 11)、t15_z0_urban(15)、t15_z0_urban_wv(32)、t12_hgtdiff(32)、t17_coords(37)、t13_mostflux(7)**;
> §三表中对它们的"显著变差"判语应视为下界。V\* 决赛圈(r_t14_noenc_cos / t15_z0,best 142)与
> θ(136)/MOST(132)/W(85)/PH(75)/zagldiff(142)/t16(95)均干净收敛,**V\* 选择与主结论不受影响**。

## 一、设置与两次修正

| 项 | 内容 |
|---|---|
| 训练 | 150 epochs 上限,valid 早停(patience 40),checkpoint 按 valid loss 选;528/72/144 小时 |
| 损失 | L1 作用于 **SI 的漂移场**(该框架的训练目标),72 通道均匀权重,无物理项 |
| 评估 | 预测与真值共用 AGL ln z 线性算子(10 m 由 U10/V10 承担);主指标 **AGL 10–500 m 平均风矢量 RMSE**;分层:昼夜 / 城郊 / 强弱风 / 相对 PBLH;显著性 = 配对移动块 bootstrap(块 24 h) |
| 基线 | ① y0 = 粗端重网格(免费,模型采样的起点);② 逐模式层水平双三次插值 |

两处修正:① 第一轮 15 个 run 用**直接输出**(模型直接给 1 km 场),结果全部劣于插值基线(见 §二),
诊断后改用**残差输出**(模型给"1 km 场 − 插值粗场")重跑 13 个 run;② 采样用确定性 ODE
(`add_noise=False`),消除采样噪声对 run 间排序的干扰。

## 二、第一轮(直接输出)结果与诊断

| run | 主指标 RMSE | Δ vs base |
|---|---|---|
| t16_residual(残差输出) | **0.963** | −0.347 |
| *y0 基线* | *1.116* | *−0.195* |
| t13_theta | 1.139 | −0.171 |
| *双三次基线* | *1.162* | *−0.149* |
| base | 1.311 | — |
| t13_w / t13_most(最差) | 1.946 | +0.636 |

13/15 个直接输出模型**打不过"不学习"的插值基线**,只有残差输出的 t16 明显更好。

诊断:① 把 base 放在**训练集**上评估得 1.339、测试集 1.311 —— 对训练过的数据一样差,**不是过拟合**;
② 均匀 L1 下 **W 通道贡献约 68%** 的损失(标准化误差 u/v ≈ 0.22、W ≈ 0.92,24/72 个通道是 W),
u/v 只占 32%;③ 漂移场估计误差在 11 步 Euler 积分中累积,直接输出下累积误差(~0.85 m/s)超过修正收益
—— 场因此比出发点还差。残差输出的修正量量级更小,同样噪声下净收益为正。

**结论**:① 13 个残差 run **全部优于双三次**,12 个优于 y0(唯一例外 r_t13_mostflux);
② 最优与基准**统计打平**的是 `cos SZA 替代四通道时间编码`(0.9601)与 `+细端 log z0`(0.9607),
按大纲 T1.4"取最简且不劣"→ **时间编码用 cos(SZA) 单通道**;
③ 其余全部增量不改善:Most 组中性(CI 含 0),θ 显著但只差 0.9%,逐层 z_agl 差场 / 地形差场 /
下垫面分级 / 坐标 / 粗端 W / 逐时 PH / 强度组均**显著变差**(+3% ~ +24%)。

**V\* = 粗端 U/V(23 层)+ 粗端逐层 z_agl + 粗端 log z0 + cos(SZA)(单通道)+ 细端几何(HGT + 逐层 z_agl)。**
输出形式为残差(1 km 场 − 插值粗场)。

| 配置 | 直接输出 | 残差输出 | 变化 |
|---|---|---|---|
| base | 1.311 | 0.963 | **−27%** |
| +MOST 组 | 1.947 | 0.973 | −50% |
| +粗端 W | 1.946 | 1.084 | −44% |
| +强度组 | 1.761 | 1.206 | −32% |
| +θ 廓线 | 1.139 | 0.972 | −15% |

残差参数化是本阶段最大的单项收益,且**改变了消融排序**(直接输出下最差的 +MOST 与 +W,在残差下
变成中性或小幅变差)——直接输出阶段的排名不具参考价值。

## 五、两层 caveat

1. **损失口径压制输入增益**:W 占均匀 L1 的 68%,u/v 只占 32%,网络优化的重心不在水平风上。
   "输入加不动"的部分原因在此,而不是这些变量本身无信息。阶段 2 的损失权重/物理约束是主要杠杆。
2. **早停偏早**:valid 损失本身随机(每个 batch 随机时间步 + 噪声),base 的最佳轮出现在第 8 轮,
   多个 run 在第 30–50 轮被早停。绝对精度可能被低估;排序在同一预算下仍可比。

## 六、工程教训(已固化)

1. **试点先于铺开**:第一轮 15 个 run(≈70 GPU 小时)在"直接输出"这个失效配置下全部作废。
   规则:任何 sweep 之前先跑单点,并与免费基线比较,确认配置"能赢"再铺开。
2. **评估链要有合成自检**:首轮评估因 3 个 bug(23/24 层混栈、排序脚本缺 sys.path、双三次自检阈值)
   白跑一轮;现 `scripts/outline/89_agl_eval_fixture.py` 覆盖算子/累加器/bootstrap/维数混用。
3. **波次要带闸门**:`59b` 现在在第 3 波及以后要求第一波评估结果存在才放行;`bsub` 不继承环境变量,
   `PHASE` 必须写进 payload(踩过一次)。
4. **PEND 即换队列**、GPU 队列白名单(Blackwell 队列与 wind3d 的 torch 不兼容)、ssh 保活
   (`ServerAliveInterval` + 服务器侧心跳)。
