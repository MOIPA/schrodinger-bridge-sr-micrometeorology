# 阶段 2 报告:损失函数与物理约束

对应大纲 T2.1–T2.4。固定 **UNet + V\* + 残差输出 + 模式层监督**,开发档 9 km→1 km(myj、23 层、块表同阶段 1)。
物理约束在 WRF 原生 C 网格上离散;产出 **L\*** 与"逐点误差 / 能谱 / 散度残差"三类净效应表。
全部比较基于同一评估链(90/92/94,配对块 bootstrap),基线 r_t14_noenc_cos 重评复现 0.9600。

## 一、设置

| 项 | 内容 |
|---|---|
| 损失项 | L1/L2 为数据项(SI 漂移场);四个输出场物理项:**散度 hinge / 涡度结构匹配 / 径向 log 谱 / 风速极值** |
| 输出场钩子 | 训练时单步可微估计 ŷ1 = y0 + b̂/dot_beta(t)(quadratic 下 = b̂/(2t)),t≥0.5 掩码,零额外前向 |
| 散度口径 | 原生 C 网格离散 ∇·(ρu),ρ 由质量点平均到面;hinge = max(0, \|D\|/τ_k − 1)²;τ_k = T0.5 d04 残差 P95(三时刻均值,ln z 插值) |
| ρ | 粗端 psfc/θ 干空气静力积分(AGL 口径,qv≈0 近似 ~1%),重网格到细端;**不进网络输入** |
| 权重 | 96 号探针在 V\* 基线 checkpoint 上定标(目标 = 各项 ≈ data 项 10%);div 三档 = 中档 1/3、1×、3× |
| 训练 | 150 epochs 上限、patience 40(诊断臂除外)、valid 选 checkpoint |
| 评估 | 90(AGL 逐时)→ 92(配对块 bootstrap);94(散度/谱/极值诊断) |

流程:先探针后训练;单点试点先行。**训练配方存在间歇性崩塌(§五),各表均标注 run 状态;结论以干净收敛的 run 为准。**

## 三、T2.3 散度约束

**机制核查(探针 + 输出场)**:训练期 hinge 作用在单步估计 ŷ1 上,其噪声下限 ≈ ε/(2√t)·σ ≈ 0.1σ(空间白噪),
散度噪声在 τ 量级 —— 基线 checkpoint 探针 frac(|D|>τ)=42.7%、P95(|D|/τ)=3.95;而**实际采样输出** frac 仅 1.5%、
P95 5.5e-4 ≈ d04 真值 4.9e-4 水平。即:残差输出模型的实际散度本来就接近真值,**训练期 hinge 主要在压估计器噪声**。

| run | 主指标 RMSE | Δ vs 基线 | 状态 | 输出散度 P95 Δ% | frac Δ% |
|---|---|---|---|---|---|
| div_lo(1/3 档) | 1.0619 | +0.1019 | 干净(best 100) | +9.4% | +27.0% |
| div_mid_warm(1× + warmup 25) | 1.0460 | +0.0859 | 干净(best 142) | −9.7% | −16.5% |
| div_mid(1× 档) | 1.1102 | +0.1502 | 冻结(14;表观差距被冻结放大) | −34.2% | −57.7% |
| div_hi(3× 档) | — | — | 冻结(未评) | — | — |
| *锚:l1_r2(基线,冻结 12)* | *1.0970* | *+0.1370* | *冻结* | *—* | *—* |

结论:① 约束机制成立(输出散度可压 −34%/−58%);② 干净配方下 div 约束仍以精度为代价(warmup 版 +8.6%);
③ 调低权重(div_lo)不改善且散度反而回升;④ 根因:τ 级散度约束对"真实散度已达标"的模型无正收益空间,
惩罚主体是估计器噪声;若继续该路线需把 hinge 改到多步 rollout 的输出场或低通散度上。

## 五、间歇性崩塌与配方修复(本阶段核心发现)

**现象**:约半数轨迹在训练早期某轮(观察到的 7~51 轮)发生**阶跃崩塌**——train/valid 同步从 ~0.11–0.13 跳到 ~0.27–0.30
并停留;无 NaN、无跳批、无报错。与输入组、损失项、物理项均无确定关系(无物理项的基线换 seed 即复现;物理项 warmup 亦不能避免)。

**崩塌是间歇性、可恢复的**(长耐心对照):
- `p2_l1_r2_long`(patience 150,seed 78269):第 13 轮掉坑 → ~110 轮恢复 → 125 轮再掉 → ~140 轮再恢复,best 0.0942@145(超过崩前 0.115);
- `p2_l1_r3`(seed 78270):22 轮仍在坑内 → 35 轮恢复 → best 0.0934@146;
- 前期所有"冻结"实为 **patience=40 早停误杀**(best 停在崩前快照,恢复前被掐停);
- 但恢复有代价:恢复型 run 的主指标仍差于从未崩的基线(+2.6% ~ +4.1%:1.0970→0.9857/1.0008)。

**修复**(在已知会崩的 seed 上对照):
- **lr 5e-4 → 2e-4:全程无坑**(147 轮),主指标 **0.9574** vs 基线 0.9601(Δ=−0.0027,CI [−0.019,+0.014] 含 0,**统计打平**);
- 余弦 lr 衰减:无效(早期仍 5e-4,同 seed 仍崩);
- L2 数据项:亦稳(2 seed 无终态崩塌;其梯度随误差衰减,L1 梯度恒为 ±1 → 5e-4 下持续满步长);
- 机理判断:步长相对损失景观过大 → 间歇性踢出;降 lr 或缓梯度(L2)可避。

**阶段 1 复查**:同款崩塌存在于阶段 1 第二轮——t14_cos(best 11)、t15_z0_urban(15)、t15_z0_urban_wv(32)、
t12_hgtdiff(32)、t17_coords(37)、t13_mostflux(7)属"早停受害者",其"显著变差"判语应视为下界;
V\* 决赛圈与 θ/MOST/W/PH/zagldiff 等干净,**V\* 结论不受影响**。

**方法学含义**:该配方下单 run 单臂 sweep 不可靠。阶段 3 起:① 训练用 **lr 2e-4**(稳定且精度打平);
② 若必须 5e-4,则 ≥2 重复/臂 + patience ≥100,按 best valid 选点。
