对应大纲 T2.1–T2.4。固定 **UNet + V\* + 残差输出 + 模式层监督**,开发档 9 km→1 km(myj、23 层、块表同阶段 1)。
物理约束在 WRF 原生 C 网格上离散;产出 **L\*** 与"逐点误差 / 能谱 / 散度残差"三类净效应表。

## 三、T2.3 散度约束

**机制核查(探针 + 输出场)**:训练期 hinge 作用在单步估计 ŷ1 上,其噪声下限 ≈ ε/(2√t)·σ ≈ 0.1σ(空间白噪),
散度噪声在 τ 量级 —— 基线 checkpoint 的探针 frac(|D|>τ)=42.7%、P95(|D|/τ)=3.95;而**实际采样输出**的 frac 仅 1.5%、
P95 5.5e-4 ≈ d04 真值 4.9e-4 水平。即:残差输出模型的实际散度本来就接近真值,**训练期 hinge 主要在压估计器噪声**。

| run | 主指标 RMSE | Δ vs 基线 | 状态 | 输出散度 P95 Δ% | frac Δ% |
|---|---|---|---|---|---|
| div_lo(1/3 档) | 1.0618 | +0.1018 | 干净(best 100) | +9.4% | +27.1% |
| div_mid(1× 档) | 1.1101 | +0.1502 | 冻结(14) | −34.2% | −57.7% |
| div_mid_warm(1× + warmup 25) | 1.0461 | +0.0861 | 干净(best 142) | −9.7% | −16.5% |
| div_hi(3× 档) | (冻,未评) | | 冻结 | | |
| *同命运锚:l1_r2(基线,冻结 12)* | *1.0970* | *+0.1370* | *冻结* | *—* | *—* |

结论:① 约束机制成立(输出散度可压 −34%/−58%);② 但相对**同命运基线**(l1_r2,冻 12,1.0970),
div_mid(冻 14)的约束净代价仅 +1.2%,即冻结污染了此前 +15% 的表观差距;③ warmup 使 div_mid 稳定跑满 150 轮
(失稳修复),但干净对照下 div 约束仍以精度为代价(+8.6% vs 基线);④ 调低权重(div_lo)不改善且散度反而回升;
⑤ 根因:τ 级散度约束对"真实散度已达标"的模型没有正收益空间,惩罚主体是估计器噪声。

## 五、冻结现象(本阶段核心发现)

约一半训练轨迹在第 7~51 轮发生**阶跃崩塌**:train/valid 同步从 ~0.11–0.13 跳到 ~0.27 平台并停留(best checkpoint 冻结在跳变前)。

- **与物理项无关**:基线同配置仅换 seed(p2_l1_r2)同样冻在第 12 轮;崩塌与输入组、损失类型、约束项均无对应关系;
- **代价锚定**:冻结的基线 best checkpoint 主指标 1.0970(+14.3%,接近 y0),即崩塌把模型冻结在"中期训练"水平;
  冻结 run 的表观差距中,大部分是训练程度的差距而非该项的代价(§三的"同命运对照"即此用途);
- **阶段 1 复查**:同款冻结存在于阶段 1 第二轮——t14_cos(best 11)、t15_z0_urban(15)、t15_z0_urban_wv(32)、
  t12_hgtdiff(32)、t17_coords(37)、t13_mostflux(7)属冻结;其"显著变差"判语应视为下界。
  V\* 决赛圈(r_t14_noenc_cos 142 / t15_z0 142)与 θ(136)/MOST(132)/W(85)/PH(75)/zagldiff(142)均干净,
  **V\* 结论不受影响**;
- **warmup(物理权重 25 轮线性爬升)可防物理项相关的失稳**(div_mid 冻结 → div_mid_warm 稳定 150 轮),
  但对无物理项的冻结(如 l1_r2)机制不同、不适用;
- **方法学含义**:单 run 单臂的 sweep 在此配方下不可靠;结论需按"干净子集 + 同命运对照"解读,
  或先做稳定性修复(lr 计划 / 更强的梯度治理)再做 ≥2 重复/臂。

## 六、L\* 与下一步

干净子集内的排序:L1(0.9600)< L2(1.0214)< div_mid_warm(1.0461)< div_lo(1.0618);冻结臂经同命运对照后无一项优于对照。
**L\* 暂定 = 纯 L1(= V\* 基线本身)**;W4 补跑完成后回填并复核 <待 W4>。

下一步:① 训练稳定性修复(优先,见 §五);② 稳定性解决后,按同预算复核谱/极值/涡度三项的干净代价;
③ 若走物理约束路线,考虑把 hinge 改在**多步 rollout 的输出场**上(消除估计器噪声对约束的污染),或改用低通滤波后的散度。
