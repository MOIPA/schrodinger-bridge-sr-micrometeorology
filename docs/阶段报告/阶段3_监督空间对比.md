# 阶段 3 报告(第一部):T3.5 监督空间对比

对应大纲 T3.5。固定 **UNet + V\* + L\*(纯 L1) + 残差输出 + lr 2e-4**,开发档 9 km→1 km(myj、23 层、块表同前)。
新增**可微 AGL 高度插值层**(与评估算子同源同参);主指标 = AGL 10–500 m 风矢量 RMSE **与切变误差**,配对块 bootstrap 95%。
基线 `p2_l1r2_lr2e4`(阶段 2 稳定性诊断的 lr 2e-4 配方,seed 78269)重评**逐位复现 0.9574**。

## 一、设置

| 项 | 内容 |
|---|---|
| 方法一 · 模式层监督 | 精度损失在 23 个模式层上计算(现状);评估时经统一算子转 AGL 交付 |
| 方法二 · 双空间联合监督 | 输出端接**固定权重、可微**的高度插值层(模式层→AGL 11 层,权重由 1 km 静态 z_agl 场构造);精度损失在**插值后的 AGL 输出**上;物理约束仍在模式层(**本阶段 L\* 无物理项**);U10/V10 不经插值层、直接监督(10 m 锚定) |
| 损失形式 | **误差场形式** L1(AGL(b̂−b_true)),b_true 与数据项同一(含 −ε√t·noise),**全 t 无掩码**;与"输出形式 \|AGL(ŷ1)−AGL(y1)\|"逐样本相差因子 2t,取误差场形式以保梯度全 t 有界、与数据项机制同构。先乘 phys_scale 反标准化再插值(σ 逐通道)。u/v 权重 1、w 权重 0.5 |
| 插值层对齐 | 与评估同源:同一 `build_agl_table` 在原生网格构表 → place 到画布 → **与字段同一次 crop** → 损失侧取 [..., :95, :111],与去交错质量网格逐像素对齐(端到端自检 max\|Δ\|=0;探针复算 rel 1.9e-7) |
| 权重定标 | 88 探针(基线 checkpoint,valid)量得 data_mean=0.1020、agl_mean=0.3006 → λ_joint = 0.339(两空间量级 1:1);等效通道权重由表解析算出(归一均值 1;1 km 以上 25 通道为 0) |
| 训练 | lr 2e-4、150 轮上限、patience 40、seed 78269;**三个新 run 全程无崩塌**(阶段 2 配方) |
| 评估 | 90(+新增切变逐时累加)→ 99 表(配对移动块 bootstrap,块长 24/12 h)→ 98 空间(陡/平 × 城/郊) |

★ 大纲 T3.5 附加消融:把 AGL 损失的等效逐层权重解析搬到模式层损失上(分离"空间对齐"与"低层加权"两种效应)。

结论:**双空间联合监督显著优于模式层监督**——主指标 −9.2%、切变 −20.5%,CI 均在 0 外且余量充裕;纯 AGL 替换数据项反而弱(主指标不显著,且 200–500 m 退化),说明"加法联合"是正确形态。逐层看,p3_joint 在 **11 层全部改善**(10 m −0.131、30–200 m −0.07 ~ −0.10、500 m −0.018),p3_agllw 在 500/700 m 反而退化(+0.046/+0.034),p3_agl 在 300–500 m 退化。

## 三、消融分解:空间对齐 vs 低层加权

| 对比 | 主指标 Δ | 95% CI | 显著 | 切变 Δ | 95% CI | 显著 |
|---|---|---|---|---|---|---|
| p3_joint − p3_agllw | −0.0206(−2.3%) | [−0.0299, −0.0112] | 是 | −0.00037 | [−0.00052, −0.00023] | 是 |

联合监督的总增益 −0.0876 分解为:**等效低层加权 −0.0670(≈76%)+ 空间对齐净增量 −0.0206(≈24%)**。
两种效应都真实存在:**空间对齐本身有独立且显著的增益**(超出其诱导的权重效应)。副产物发现:"重塑权重"(agllw)会牺牲 >300 m 高层精度,而联合方式(保持原损失 + 加法项)全层不退化——低层增益不必以高层为代价。

## 五、工程与稳定性备注

- lr 2e-4 下三个新 run 无崩塌(p3_agl 早停于 85 轮,p3_joint/p3_agllw 跑满 150);基线重评与阶段 2 结果逐位一致(确定性采样)。
- 探针复核:框架内 AGL 项与公共 numpy 算子复算一致(rel 1.9e-7);训练侧表与评估侧 `load_tables` 逐元素相等。
- 冻结插值算子 `idx==-1` 分支(目标低于首模式层)权重方向与解析值不符——**本域内该分支触发 0 像素**(10 m 由 −2 锚定、其余目标均高于首层 24.7 m),预测/真值同算子故评估自洽;按协议冻结未改,已记录。
- 待办(**尚未做**):种子重复臂(验证 −9.2% 非种子幸运,建议补跑)、λ 敏感性(可选)、层集合 40 层字面口径(待与导师确认)。

## 六、结论

1. **大纲 T3.5 有正面答案**:监督空间的选择有实际影响;双空间联合监督(模型层 L1 + λ·AGL)是当前最优监督方式(M\*/S\* 候选)。
2. 增益机制已分解:低层加权 ≈ 76%、空间对齐独立贡献 ≈ 24%(均显著)——消融设计达成大纲"分离两种效应"的目标。
