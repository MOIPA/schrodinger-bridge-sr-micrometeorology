**关于约束对象"漂移场 b vs 输出风场"的准确表述**(2026-09-22 澄清):

最终风场 `y1 = y0 + ∫b dt`,故 `∇·y1 = ∇·y0 + ∫(∇·b)dt`。两种约束**不等价**:
- 约束 ∇·b = 0 ⇒ 最终场**继承 y0 的散度**(只保证修正过程不额外引入散度)
- 约束 ∇·y1 = 0 ⇒ 直接压制最终场散度(含修掉 y0 带来的部分)
- 两者恰好相差 ∇·y0;且逐步骤约束 b 否定"中途正负散度抵消"的漏洞,只压终点则不然

即使把约束移到输出风场,与大纲仍差三处实现口径:① 我们差分除以**索引间距**(未用物理 dx、未按真实层厚——ml0→ml1 与 ml5→ml10 层厚相差数倍,等间距假设使 ∂W/∂z 项权重失真);② 无密度场(不可压缩近似 vs 可压缩 ∇·(ρu));③ 压向 0 而非对齐 d04 真实残差统计(WRF 自身散度残差非零,压向 0 过度约束)。

## 2. 关键偏差排序(最需要在下一步对齐的)

1. **监督/评估空间**(T0.2/T0.3/T3.5):大纲从训练空间到评估空间都与我们不同,且"监督空间选择"是其核心创新——我们完全空白,**这是最大结构性偏差**
2. **开发档位**(阶段 1):大纲以 9 km→1 km 为开发档;我们主线 3 km。数据已确认(d02 存在),流程可复用 d03 预处理脚本
3. **变量体系**(T0.2/T1.3):大纲的"必须项"含 z_agl 逐层通道、log(z0)、时间编码;消融变量含 RMOL/UST/θ 廓线(我们库里没有,需从 wrfout 提取);大纲明确**排除**的变量(TSK、LH、辐射)我们在用
4. **防泄漏口径**(规则二):大纲要求**逐时刻量只从粗端取**(1 km 端只提供静态场)——我们的 baseline 用 1 km 条件(≈泄漏),反倒是我们的 **allLR 实验(全 3 km 条件)与大纲口径一致**,已有结果可直接复用
5. **标准化规范**(T0.2):风分量不平移(我们平移了)、逐层 σ、粗细端独立——影响风矢量几何与可比性
6. **物理约束口径**(T2.3):原生 C 网格 + 可压缩 ∇·(ρu) + 残差定标;我们在漂移场 b 上做不可压缩近似——若大纲是主线,需改成对**输出风场**在原生网格上约束
7. **数据划分**(T0.6):块级连续划分 + 无 myj/ysu 泄漏;我们现划分需重做
8. **时间降尺度**(阶段 5):完全空白
9. **观测锚定**(阶段 6):完全空白;观测数据(GHCN/IGRA)在共享库中
