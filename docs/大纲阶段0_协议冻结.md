### 2.4 标准化(表 7,落地口径)

统计量**只在训练块上计算**;粗细端各自统计;公式与取值全部在 `normalize_config.json`:

| 通道 | 变换 | μ | σ |
|------|------|---|---|
| 细/粗端 U、V | 无 | **强制 0(不平移)** | 逐层,σ_k = √(mean(U²+V²)/2),U/V 共用 |
| W | 无 | 强制 0 | 逐层独立(界面层) |
| U10/V10 | 无 | 强制 0 | 单层合并 |
| RMOL | `z₁·RMOL` → `sign·log(1+|·|)` | 变换后样本均值 | 变换后标准差 |
| UST / PBLH | 自然对数 | 同上 | 同上 |
| HFX / T2 / PSFC | 无 | 常规 | 常规 |
| θ 廓线 / PH | 无 | 逐层 | 逐层 |
| z_agl | 对数 | 全层统一 | 全层统一(唯一不逐层) |
| log(z0)/HGT/urban/water/vegfra | — / 对数(z0) | 全域统一 | 全域统一 |
| hour/doy sin·cos、cos(SZA) | 不处理 | — | — |

- 评估与物理约束一律**先反标准化回物理单位**。
- 实测 σ 廓线与异常排查图:`results/outline/sigma_profiles.png`(运行 40 号脚本后生成)。
- 时间编码用**本地时(UTC+8)**的 hour 与 doy(记于协议)。
