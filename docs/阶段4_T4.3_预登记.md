## 1 假设 ①（辅助变量的边际价值随跨度增大）

- **支持**：27→1 上 `aux` 相对基准的 Δ < 0 且 CI 不含 0；同时该 Δ 的绝对值大于 9→1 上对应组的负收益量级。
- **不支持**：27→1 上仍为负收益（哪怕不显著），或正收益但幅度小于 9→1 的负收益。
- 只能写"在我们这一组配置与月份上"；不能外推成"辅助变量在任意跨度都值钱"。

## 2 假设 ②（粗端 W 的价值随分辨率变化）

三档证据合成一条判断：

| 27→1 加 W | 3→1 加 W | 判读 |
|---|---|---|
| 无收益/更差 | 有收益/更好 | **原预期成立**（3 km 有用、27 km 无用） |
| 都无收益/都更差 | | 预期被推翻（W 在任何分辨率都不值钱） |
| 都有收益 | | 预期被推翻（W 在粗端也有用，与"27 km 解析不出 W"矛盾） |
| 27→1 有、3→1 无 | | 与预期反向，需单独解释 |

## 3 判据与禁止写法

- 统计口径与阶段 4a 完全一致：主指标 AGL 10–500 m 矢量 RMSE、配对移动块 bootstrap（块 24 h、2000 次）、同一批 test 时次（2020-07-16T00–07-31T23）。
