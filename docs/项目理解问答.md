## 0. 一句话理解整个项目

用深度学习把 9km 分辨率的粗风场"放大"成 1km 的精细三维风场(近地 10–1000 m):

- 网络(UNet,扩散类框架)不跑物理方程,而是从历史样本学"粗场 → 细场"的对应关系,本质是数据驱动的降尺度(与图像超分同源);
- 训练时学的不是"一步预测",而是"从粗场逐步修正到细场"的迭代方向;推理时积分 11 步出结果(好处:未来可做集合预报/给不确定性);
- 评估时把预测与真值都插值到统一的物理高度层(AGL 11 层)上比较。

**已完成的三个阶段 = 三个设计决策**:

| 阶段 | 回答的问题 | 结论 |
|---|---|---|
| 0 数据工程 | 数据怎么切、什么算"对" | 协议冻结(23 个模式层输入输出、AGL 11 层评估、块级划分) |
| 1 输入消融(28 个 run) | 网络"看什么" | V\* 输入组;最大单项收益 = 残差输出(−27%) |

| 3 监督空间(进行中) | 在哪里打分 | 联合监督:主指标 −9.2%、切变 −20.5%,均显著(W1 已出) |

## 1. "冻结协议:输入输出 23 个模式层"是什么意思,冻结谁

"冻结" = 开工前把关键设定一次性敲定,之后所有实验都按同一套执行(类似临床试验先注册分析方案):这样任何两个实验的差异才能归因到我们改的那一个点。

冻结清单(2026-09-27 定稿,`docs/大纲阶段0_协议冻结.md`):

- 数据划分:按天气过程切连续块,valid = 块 0、test = 块 5+块 9;
- 训练层集合:23 个模式层(= 1 km 以下 20 层 + 上方 3 个背景层);
- 固定 myj 参数化方案(ysu 留给阶段 6 泛化用);
- 评估空间:AGL 11 层(10–1000 m)+ 统一 ln z 插值算子;
- 标准化口径:风只缩放不平移、逐层 σ、粗细端统计独立。

"23 个模式层":WRF 垂直方向是 61 个随地形起伏的 eta 层;我们抽出 40 层,再选定 23 层作为网络的输入与输出(覆盖目标交付高度 1 km 以下的 20 层 + 3 个背景层;垂直风在 24 个界面上)。报告的跨阶段数字可比,全靠这把"尺子"不变。

备注:导师大纲有"2 km 以下所有层"(40 层)的字面口径,已列入待沟通清单;若要按字面来,改一个配置参数重跑即可。

## 2. 阶段 1 的输入消融 = 看哪个输入变量最好、贡献最多?

机制对:每次只增/删一组变量,完整重训一遍,在同一测试集上比较;只有"去掉它之后显著变差"(块 bootstrap CI)才算有贡献。但实际结论有三层:

1. **变量层面以否定为主**:MOST 参数组(RMOL/UST/PBLH)、θ 廓线、粗端 W、强度组、下垫面分级、坐标——都不改善,多数还显著变差。"输入不是越多越好";最优输入集 V\* ≈ 基线集(仅用太阳角度编码替换时间编码),此后所有阶段固定用 V\*。
2. **最大单项收益不在变量**:输出形式从"直接预测风场"改为"预测修正量(细场−粗场)",误差 −27%(1.31 → 0.96)。
3. **顺带诊断出阶段 2 的动机**:均匀 L1 损失里垂直风 W 占 68%、水平风 u/v 只占 32%,输入增益被压制 → 杠杆可能在损失函数。

## 3. 阶段 2 = 选择最好的损失函数?

更准确:"怎么打分,以及要不要把物理规律写进打分"。

- **数据项形式**:L1 vs L2 vs L1+谱损失 → **L1 最好**(L2 差 6.1%,谱损失更差);
- **物理约束项**(大纲创新点,四类):散度(连续性,可压缩 ∇·(ρu),hinge 惩罚超出真值残差的部分)、涡度结构匹配、能量谱、极值(max/min)——权重先探针定标再训练。结果:**四项全部负收益**(+4.2% ~ +15.7%),高阶统计量(谱/极值)危害最大。机制:散度约束训练时作用在"单步估计器"上,主要在惩罚估计器噪声;而实际输出场的散度本就已接近真值,没有可压空间。因此 **L\* = 纯 L1**。
- **意外收获(最重要)**:发现训练存在**间歇性崩塌**——约半数实验中途损失突然跳高到平台(与配置无关,换种子就复现),旧早停机制会误杀这类 run。根因是学习率;**修复 = lr 2e-4**(全程稳定、精度打平最优)。此后所有阶段标配该配方。

## 4. 阶段 3 的监督空间 = 把模式层映射到实际物理高度?

映射一直存在(评估与交付都需要);创新点是**把这个映射搬进训练**:

- **方法一 · 模式层监督(旧)**:网络的输出在 23 个模式层上与真值对齐;评估时再插值到 AGL 比较——训练打分的位置与最终打分的位置"错位";
- **方法二 · 双空间联合监督(新,大纲核心创新)**:输出端接一个**固定、无参数、可微**的高度插值算子(与评估同一套),精度损失直接算在插值后的 AGL 输出上;物理约束仍在模式层;U10/V10 不经插值层直接监督;
- **为什么有效**:损失的逐层有效权重结构变了(见 §7),且训练信号直接追踪评估口径的聚合方式;
- **已出结果**(144 小时测试集,块 bootstrap 95%):联合监督主指标 **0.8697 vs 基线 0.9574(−9.2%)**、切变 **−20.5%**,全部显著;纯 AGL 监督切变 −9.9% 显著、主指标 −2.0% 不显著;收益集中在 10–150 m 低层。

## 5. 评估时"插值到物理高度"具体怎么做

查表 + 两点加权平均,逐像素进行:

1. **离线算一次**:每个网格点上每个模式层的离地高度 z_agl 是静态已知量(由 PHB 与地形 HGT 导出,不随时间变)。对每个目标高度 h,找到夹住它的两层 k(z_k ≤ h)与 k+1,以及权重。表(层号与权重)只取决于地形几何,存一次即可。
2. **每帧插值**:`f(h) = w·f(k) + (1−w)·f(k+1)`,权重按 **ln z 线性**(近地风廓线近似对数律):`w = (ln z_{k+1} − ln h) / (ln z_{k+1} − ln z_k)`。
   例:某像素模式层高 72 / 104 m,目标 100 m → w ≈ 0.106 → 100 m 风 = 0.106×f(72) + 0.894×f(104)。
3. **特殊情形**:10 m 目标直接用 WRF 自带 U10/V10;目标低于首层(大地形处)按同一公式与 10 m 值混合;超出范围不外推(取最近层)。垂直风 W 用"界面层"的另一张表。
4. **两个要点**:预测与真值走同一个算子(比较公平);插值自身的往返误差已量化(u ≈ 0.15 m/s ≈ 11% 信号),远小于模型误差,不是瓶颈。

## 6. 澄清:那不是"一层神经网络";W2 消融到底在验证什么

- **不是神经网络层**:那个插值算子是固定操作——无参数、不可学、权重来自地形几何,唯一要求是"可微"(梯度能回传)。网络本体完全没变(同一个 UNet、同样输出 23 个模式层)。这点关键:如果它是可学习的,"两种方法唯一差异是打分空间"的结论就不成立(等于同时改了模型能力)。
- **W2(p3_agllw)不是验证"是不是这个层导致的"**,而是分离两种竞争解释:**空间对齐本身** vs **隐含的低层加权**。怀疑者会说:把损失搬到 AGL 空间,不过是把低层权重加大了——而这种加权在模式层里手工就能做,毫无创新。大纲因此要求这个附加消融。
- **W2 的做法**:用冻结插值表**解析算出**"AGL 损失等效诱导的逐模式层权重"(域平均、归一到均值 1),把它作为方法一(模式层损失)的逐通道权重,单独训一臂。判读:若 W2 拿到与 p3_joint 相当的增益 → 好处主要来自低层加权;若 W2 明显更小 → 空间对齐有独立价值。
  (更细一层:AGL 损失与"逐层加权"并不严格等价——误差在取绝对值之前先被插值平均了,这部分结构差异也由 W2 对照衡量。)

## 7. "隐含效果是把低层的权重加大了"怎么理解

损失搬到 AGL 空间后,没有人写"低层 ×3",但有效权重自动重新分配(所以叫"隐含"):

- AGL 的 11 个目标高度**低处密**:9/11 在 500 m 以下、5/11 在 100 m 以下;
- 每个目标高度的值由夹住它的两个模式层插值而来 → 低层模式层参与多个目标的插值,反复"分到"梯度;1 km 以上没有目标层需要它 → 权重为 0;
- 对比:方法一里 23 层**等权**(其中 1 km 以上 3 个背景层占着 ~13% 的损失份额,却是评估盲区);方法二自动把这份额挪给低层。
- 实测(探针解析值,相对均匀权重 = 1):第 0/1/2 层(≈25–70 m)有效权重 **2.8 / 4.7 / 2.2**,中低层 ≈1.0–1.2,1 km 以上 = 0。
- 类比:11 场考试里 9 场考前 5 章——"为考试复习"自然把精力集中在前 5 章。

## 8. 为什么实验很多、报告却很短;累计做了多少

- **报告是结论清单,不是实验台账**(风格:零装饰、密度优先)。实验的信息结构 = "一个结论 + 一张排序表";排除类结果天然只占一行(如"15 个直接输出 run 全部劣于插值基线"这一句 ≈ 70 GPU 小时)。
- **大量工时花在"不变形"上**:数据工程、协议冻结、合成自检、评估链、探针定标、可微算子——不产生发现,但没有它们数字不可信,报告里只占"实现资产"一小节。
- **负/正结果不对称**:大部分实验是负结果(每个砍掉一片搜索空间,报告里半行);真正的"肉"只有三块:V\*、崩塌 + lr 修复、AGL 监督。
- **验证成本不可压缩**:一条结论 ≈ 3–5 个 run + 统一评估 + bootstrap ≈ 30–50 GPU 小时 → 落到报告是一行。单点结果不可信,消融 + 显著性是底线。
- **工时审计**(服务器现存日志):**248 GPU 小时**(3734 个训练轮、36 个训练日志);被覆盖日志未计,实际估 **350–450 GPU 小时**;此外还有数据抽取(CPU、数千文件)、几十次评估/探针/自检与本地开发。
