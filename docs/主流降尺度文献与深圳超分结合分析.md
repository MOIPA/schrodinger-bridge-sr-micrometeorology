# 主流大气降尺度文献(导师推荐 8 篇)与深圳超分工作的结合分析

> 2026-09-05。背景:导师反馈深圳跨域实验"设计太乱",推荐 8 篇论文(重点 4 篇),摘要见 `~/文档/tzq_work/paper/论文总结/`(原始 PDF 同目录)。本文回答三个问题:**我们的工作与这些论文各处于什么位置、能借鉴什么、实验该怎么重组**,并对齐到具体行动(脚本/代码/报告)。

## 0. 一句话结论(先看这个)

**我们手上有这 8 篇都没有的"干净实验台"——同一 WRF 模拟的两个嵌套域(d03 3km ↔ d04 1km)天然构成"真实低精度配对",还能与合成降采样做双轨对照。** 我们缺的不是方法,而是三样东西:**外部锚点**(零模型/插值基线、判别式回归对照)、**科学评价工具**(功率谱、PDF 尾部、分箱误差,乃至 CRPS/校准)、**规范的对照组织**(设计矩阵 + 泛化留出)。导师说"乱",是因为 9 个模型的差异全在内部变体之间,读起来是一串消融,没有外部参照物;8 篇论文恰好展示了这类工作公认的"实验骨架"。

## 2. 我们的独有位置:有什么是他们没有的

### 2.1 独有资产(论文写作的卖点素材)

1. **同一模拟的嵌套双域真实配对(d03↔d04)**。Benton/CorrDiff/Sun 的"真实 LR 配对"都是**异源**的:ERA5(再分析/同化)→ WRF/再分析,域差里混着同化注入、模式版本、物理方案的差异,退化不可控。我们的 d03 与 d04 出自**同一次 WRF 模拟**(同模式、同物理、同垂直坐标、同一模拟时钟),LR 与 HR 的差异被隔离为"纯分辨率/网格平滑"——是研究 real-world 退化的**最干净实验台**,且时间戳精确到秒配对、零丢弃。
2. **"合成 LR 训练 vs 真实 LR 训练"的双轨对照(四格矩阵)**。8 篇论文全是用真 LR 直接训练(或全用合成),**没有人系统量化过"合成降尺度训练 → 真实低精度部署"的偏移**,更没人做过"用真实 LR 重训是否追回"的对照(我们:d03 同域 0.286 反而差于跨域 0.241)。这是稀缺的对照实验,但负结果需要讲透(1km 细节在源头缺失,逆问题不可恢复),否则读起来就是"乱"。
3. **多层三维边界层风场(含 W)+ 物理约束的严格同架构消融**。CorrDiff/Sun 是地表或整层 2D 化处理,只有我们和 Kurihanna 在边界层多层含 W 的 3D 场上做;散度/涡度约束的"有 vs 无"、且同架构同数据,8 篇里没有等价的严格对照(02/07 建议过但没系统做)。
4. 条件变量齐全(地形 z、土地利用 lu、感热/潜热、PBLH 等 8 个 1km/3km 双版本)——尤其地形与下垫面,后文 3.2 说明它们被证明是最高价值输入。

### 2.2 共享基础(说明我们站在同一条主线上)

- 与 01/05/06 同属"**真实 LR 配对的学习降尺度**"主线(而非合成粗化玩具);
- 与 03 的任务公式几乎一致:LR 已插值/重采样到 HR 网格,**网络只学细节修正**(我们的输入 y0 与输出同网格,天然残差结构,和 Ericson 的做法、Sun06 的全局残差连接同思路);
- 与 05/06 同为**扩散族生成模型**;与 02/04 同为多变量含 W 的 3D 风场。

### 2.3 我们的缺口(8 篇反复出现而我们没有的东西)

| 缺口 | 8 篇里的对应 | 对我们的直接后果 |
|---|---|---|
| **零模型/插值 baseline** | 几乎每篇都有(03 的线性插值、05 的 ERA5 插值、02 的粗输入谱) | 所有 RMSE 没有"兜底参照",无法回答"模型干了多少活" |
| **判别式回归对照** | 03 全套回归、05/06 的回归 UNet 消融 | 无法论证"扩散/生成"的必要性——审稿人必问 |
| **功率谱/分布诊断** | 01 动能谱、02/04/07 谱、05 谱+PDF、08 能谱误差 | 没有证据说明输出"高频细节真",RMSE/SSIM 会掩盖过平滑 |
| **分箱/极值误差** | 03 高风分箱 MAE、01 极值损失与 MRQE | 我们最关心的垂直风/强风表现被总量指标稀释 |
| **概率/不确定性**(我们本可做的) | 05/06 CRPS、校准、集合方差 | 扩散模型单样本 RMSE 天然不占优,不展示 CRPS/校准就白用了扩散 |
| **泛化留出协议** | 03 地理切片留出 + 陌生地形、01 域外年/跨洲 | 我们只有单城单月,唯一现成的留出维度(两套 PBL)没用上 |
| **观测/业务验证** | 01 测风塔/MADIS、06 业务 MAE 对比 | 模式-模式闭环,说服力上限被封 |

## 3. 重点 4 篇逐篇:导师为什么发这篇 + 我们的结合点

### 3.1 ⭐ Benton 2025(Energies,GAN 工程标杆)

**她让你看的**:真实 LR 配对(ERA5↔WTK)不是"粗化 HR 假装 LR",这正是我们 d03 想做的事——但 Benton 把它做成了**完整的工程闭环**:真配对 + 偏差矩匹配 + 级联放大 + 分布/极值评价(MRQE、KS、动能谱)+ **测风塔/站点观测验证** + 跨洲外推。
**点我们的问题**:我们在"真实 LR"上只走到训练/评估;没有观测端验证,也没有"模型预测 vs 输入本身"的增益量化。
**结合点**:
- 我们与它最像的是"第一级吸收域差"的思想——我们把模拟/真实域差直接做成了**独立变量**(双轨),这是升级版,写作时值得强调;
- 极值项损失(把时空 min/max 拉近)对我们的 W 分量或强风可能直接有用,低成本可试;
- 它的评价清单(KS、MRQE、日循环、变率分布)是我们 2.5 节指标体系的升级方向。

### 3.2 ⭐ Ericson 2025(QJRMS,判别式公平评测)

**她让你看的**:同是"模式 LR 插值到 HR 网格、学细节修正",他们系统横向对比 9 种回归架构,结论:**判别式回归(尤其 Uformer)已经大幅碾压线性插值(幅值差 0.99 vs 1.52 m/s)**,且给出 MSE-参数量权衡、**高风分箱误差**、**地形/气压最重要、湿度云量可裁剪**的输入消融、跨地形泛化测试。
**点我们的问题**:① 我们**从没和"不用生成模型、直接回归"比过**——如果回归就够了,我们的扩散 + 物理约束叙事就没有立足点(反之,如果扩散在谱/细节上赢了,我们就有 03 没有的对照);② 我们的 SSIM/Corr 总量指标会被海量弱风样本稀释,看不到强风段表现。
**结合点**:
- **补一个判别式回归对照**(同 UNet 骨架、直接回归 18 通道,或至少把我们的 SI 网络退化为 t→0 单步确定性预测)——这是回答"生成式是否必要"的最低成本实验;
- **评估加分箱**:按真值风速强度(或按 U/V/W 分层)给相对误差,仿"高风专家"叙事,我们的 W 分量故事会清楚得多;
- **输入消融(shuffle)**:8 个条件变量谁是关键(预期地形 z、psfc、tsk 高,lu 低?)直接支撑"条件精度降级(allLR)为什么伤"的解释;
- **地形是最重要输入**与我们的 allLR 实验互相印证——条件输入掉精度(3km 条件)的伤害会被地形等高价值通道放大。

### 3.3 ⭐ Mardani 2025 CorrDiff(CEE,扩散范式源头)

**她让你看的**:生成式降尺度当前最主流做法的"均值回归 + 残差扩散"两段式;评价体系(CRPS、功率谱、PDF 尾部、校准 rank histogram、个例锐度);以及核心主张——**扩散的价值在"分布真实"与"概率校准",不在单样本 MAE**(CorrDiff 的 MAE 还略差于回归 UNet,但 CRPS 205/205 全胜)。
**点我们的问题**:我们的 SI 扩散目前只输出单样本、只报 RMSE/SSIM——等于**用回归的尺子量生成模型**,扩散的优势(多解、方差、尾部)全没用上,而劣势(训练不稳)全暴露。这就是"物理约束模型绝对精度不占优"这类结果读起来无力的部分原因。
**结合点**:
- 短期:给 SI 加 **ensemble 采样**(同一输入多次采样),报 CRPS/spread–skill,哪怕只在一组子集上,就能回答"我们的生成模型有没有概率价值";
- 中期:**"回归均值 + 扩散残差"两段式**直接可试:把现有 SI 网络对"回归预测残差"建模(输出通道不变,目标换成 r = y − UNet(x))——这与我们"只学细节修正"的结构天然兼容;
- 其谱/PDF 诊断脚本(功率谱幂律、log-PDF)可以直接照搬到我们的评估(见第 5 节 P0 行动)。

### 3.4 ⭐ Sun 2026(arXiv,CorrDiff 中国 3km 扩展)

**她让你看的**:① CorrDiff 范式在大区域 + **高空 6 层三维场**上落地(我们也是多层三维);② **全局残差连接**(学 y − bilinear(x),恒等跳线绕过网络)——几乎免费的结构改动;③ **以业务区域模式为 baseline 的端到端对比**(降尺度链路 MAE 优于 CMA-MESO);④ 误差级联结论(输出误差主要继承自输入);⑤ 小 batch、按层归一化等训练工程。
**点我们的问题**:我们目前所有结论都是"模型间相对",没有像它那样挂一个"业务系统/插值"的绝对锚;也没有按层/按分量的分解叙事(我们有分量表但没有"层"维度的讨论)。
**结合点**:
- 全局残差连接:我们输入已与输出同网格,加一条恒等跳线是数行代码的事,值得消融;
- **按层评估**(ml0→ml10 逐层 RMSE/谱):我们 6 层横跨近地面到边界层顶,物理上应有清晰的分层故事(参考我们历史报告里 ml0 vs ml10 的差异),目前完全没展开;
- 业务对比叙事:深圳 case 没有"业务系统",但我们有 d03 原生场本身(零模型)与 WRF d04(真值)两个天然锚,足够撑起"AI 链路 vs 原生场"的故事;
- 其"扩散单样本 MAE 高于回归、CRPS 反超"的坦诚叙事,正是我们 pinn/扩散模型结果"不好看"时的正确讲法模板。

## 4. "实验太乱"的诊断:他们的实验骨架 vs 我们的现状

### 4.1 乱的根源

我们的 9 个模型(baseline/allLR/day/night/phys × d04/d03)全部是**同一框架的内部变体消融**(改条件精度、改物理权重、改训练数据源)。它们彼此之间只差一两个旋钮,读完给人的信息是"谁比谁好一点",但缺少三根柱子:

1. **没有下限锚**:不知道"什么都不学"(插值/零模型)是多少 → 所有增益没有绝对刻度(47 号脚本在补);
2. **没有侧向锚**:不知道"不用生成/不用物理"的同行模型是多少 → 扩散和物理约束的价值无法归因(只有 phys 一个消融点);
3. **没有物理统计量**:RMSE/SSIM 只测"逐点像不像",测不出"高频细节真不真、分布尾对不对"——而这是生成式工作唯一能赢的战场。

另外,9 个模型的差异轴没有画成**设计矩阵**呈现,负结果(同域训练更差、phys 中途最优)也没有正面归因框架,信息像"流水账"而不是"对照实验"。

### 4.2 公认的论文实验骨架(8 篇共同形态)

每篇基本都长这样,我们逐条对照:

```
① 设定锚点:插值/零模型/输入本身 作 baseline        ← 我们缺(47 号补)
② 模型族对照:回归 vs 生成(GAN/扩散),同数据同协议  ← 我们缺(只有一个扩散族)
③ 公平协议:统一采样/损失/留出,报告权衡曲线        ← 我们缺(9 个模型无统一协议叙事)
④ 物理诊断:功率谱、PDF 尾部、分箱、剖面           ← 我们缺
⑤ 概率价值(生成式):CRPS、校准、集合              ← 我们缺
⑥ 泛化:时间/空间/模式留出、异地测试              ← 我们有"模拟 vs 真实"跨域,但没用上模式留出
⑦ 观测/业务锚:站点验证或业务系统对比             ← 我们缺(远期)
```

### 4.3 实验重组建议(面向论文,不再加新模型的方案)

把现有 9 个模型与补上的 2~3 个锚整理成**三条对照轴**讲,天然有序:

| 轴 | 做什么 | 回答的问题 |
|---|---|---|
| 轴 A:退化类型 | 模拟低精度 vs 真实低精度(同模型家族,即现有 d04/d03 双轨) | 合成训练够不够?真实训练能否追回?(我们独有) |
| 轴 B:模型能力 | 零模型/插值 → 判别式回归(补)→ SI 扩散 → (+物理约束) | 每加一层能力/约束带来多少增益?扩散值不值? |
| 轴 C:输入完整性 | 1km 条件 vs 3km 条件(即 allLR 系列) | 条件精度降级的代价,真实部署中的取舍 |

现有 day/night 分训模型作为**消融副产品**降级到补充材料(导师视角里它最像"乱加的变量")。物理约束(phys 系列)挂在轴 B 顶端作为"扩散 + 物理"一档,配 4.1 的工程结论(需要早停/两段式,见第 5 节 P2)。

### 借鉴时的三个"别学"(避免走弯路)

1. **别学 01/02 的级联放大**——我们跨度只有 ×3,单级足够,级联是他们的 ×15/×32 才需要的;
2. **别把 day/night 当主线**——8 篇里没有一篇把昼夜分训当核心实验,它更适合作为消融/补充;
3. **别指望直接复刻 05/06 的两段式就解决 pinn 不稳定**——他们的回归阶段本身不含约束,约束怎么进框架(进均值网还是进残差网)值得先小规模验证再承诺(P2)。

## 6. 一条可讲的故事线(未来论文骨架)

1. **设定**:同一 WRF 模拟嵌套域构成"可控真实退化"实验台(3km↔1km,6 层边界层三维风,含 W);
2. **主问题**:模拟退化训练的扩散超分,在真实低精度输入上掉多少?真实数据重训能否追回?
3. **方法**:SI 扩散 + 运动学物理约束(两段式/自适应权重升级版);
4. **对照**:零模型/插值 → 判别回归 → 扩散 → 扩散+物理(同协议);模拟 vs 真实 LR 双轨(四格矩阵);
5. **诊断**:RMSE 等误差 + 逐层分解 + 功率谱 + 分箱 + 模式留出泛化(甚至 ensemble CRPS);
6. **结论**:真实退化 ≠ 合成退化(W 分量最敏感,偏移 +22~61%);真实同域训练受信息不可逆限制——数据工程(联合训练/增强)是正路,而非简单重训。

其中 1、2 是**独有**,5 是**补课**,6 已有全部数字支撑,只差 4 的判别回归锚与 3 的稳定性改造——这两块做完,实验就不再"乱",而是三条轴一个矩阵的完整故事。
