# 学习笔记

## 〇、背景

项目的任务是把深圳 WRF 的粗网格风场超分到细网格:用粗档位的模拟结果"加细"成更细网格的风场(比如用 9 km 的场造出 1 km 的场)。后面的"交错网格""去交错""插值对齐"等名词都围绕这条主线。

---

## 一、"3 km → 1 km"和"9 km → 1 km"到底指什么

**困惑点**:组会报告开头一句"开发档位改为 9 km 至 1 km"。"改为"说明存在"原来的"档位,但原来到底是从几到什么,并不清楚。

**理清之后**:这套模拟是 WRF 四层嵌套,每往外一层粗 3 倍:

```
d01       d02       d03       d04
27 km  →  9 km  →   3 km  →   1 km
```

超分任务 = 拿粗档位的场,造出细档位的场:

- **旧线(已冻结)**:3 km → 1 km,即 d03 → d04;
- **新线(导师大纲)**:9 km → 1 km,即 d02 → d04。现在报告里所有新数字都是这条线。

**容易踩的坑**:两份报告的数字不能混着比。跨度从 3 倍变成 9 倍,要凭空造出的信息量差一个量级,任务明显更难,指标看起来"变差"是正常的。旧线没作废——后面"跨分辨率迁移"实验里 3 km 档还会作为对照重新出场。

---

## 二、Arakawa C 网格:变量不放在同一个点上

**缘起**:报告里写"保留 WRF 原生 Arakawa C 网格交错位置,不做插值对齐"。每个字都认识,连起来看不懂。

### 2.1 它是什么

Arakawa C 网格是数值模式的"变量摆放规则"。俯视一个格子:

```
        v
   ┌────•────┐
   │         │
 u •    T    • u
   │         │
   └────•────┘
        v
```

- **T**(温度、气压、水汽等标量)放在格子中心;
- **u**(东西风)放在左右边(界面)的中点;
- **v**(南北风)放在上下边的中点;
- **w**(垂直速度)放在垂直的层与层之间。

也就是说,**不同变量的位置互相错开半格**——这就是"交错网格"名字的来源。

### 2.2 卡点:两个格子共享一条边,"U"是不是重复或矛盾了?

第一反应容易把数据想象成"每个格子打包一套变量":格子 1 有自己的 u,格子 2 也有自己的 u,并排摆在一起,中间那条边到底听谁的?

**解开的关键**:数据不是"每格一套",而是**几套错开半格的点集**:

- 质量点集:存 T 等标量,在格子中心;
- u 点集:存东西风,在质量点之间的中点;
- v 点集:存南北风,在另一方向的界面中点。

一维看最清楚:

```
      u₀       u₁       u₂       u₃
      •   T₁   •   T₂   •   T₃   •
      |←─ Δx ─→|
```

u₁ 同时是格子 T₁ 的右界面、格子 T₂ 的左界面——**同一个值、只存一份、两边共用**。

而且这很合理:u₁ 的物理含义就是"穿过这条边、在左右两格之间交换的流动"。两格之间的交换量本来就是一回事,不存在"格子 1 的 u"和"格子 2 的 u"两个东西。共用一份,不重复、不矛盾,守恒写起来也自然——从格子 1 流出去多少,正好流进格子 2。

### 2.3 为什么模式要把变量错开放

如果所有变量都挤在同一个格点上,用中心差分算气压梯度力时,相邻格点会"各算各的",出现棋盘格式的虚假振荡(计算模态)。C 网格下气压梯度、散度直接用相邻界面的值算,不用先做平均,既紧致又干净,还有好的守恒性质。所以这是数值模式的经典设计(荒川昭夫,1977),WRF 用的就是它。

## 三、"插值对齐"与"去交错":为什么对齐反而丢东西

### 3.1 模型为什么要"对齐"

深度学习模型把风场当**多通道图像**处理,卷积默认各通道像素在同一位置对齐——`u(i,j)` 和 `v(i,j)` 被当作同一个点的两个分量。但原生数据里 u 和 v 差半个格距的斜距,u 和 T 差半格,相当于一张"RGB 三通道互相平移了半像素"的图。

为图省事,常见做法是先把 u、v 平均到 T 点上:

```
u_T(i) = [ u(i−½) + u(i+½) ] / 2
```

这一步叫**去交错**(destagger)。对齐之后任何标准网络拿来即用,很多超分工作就是这么预处理的。

### 3.2 平均会丢细节:丢的是什么,丢多少

对波长 λ 的波动,这个平均把幅度乘以 `cos(π·Δx/λ)`:

| 波长 | 平均后剩下的幅度 |
|------|:---:|
| 2Δx(最短波) | **0%,完全消失** |
| 4Δx | 71% |
| 7Δx | 90% |
| 20Δx | 99% |

最短的波在 u 序列里正负交替,平均时左右互相抵消——**完全消失**;波长越长损失越小。所以它本质上是一次**低通滤波**:把半格错位"抹平"的过程,顺带把小于一两倍格距的起伏也抹平了。很多人以为去交错只是坐标搬移、无损,其实不然。

而且**不可逆**:两个数平均成一个数,自由度少了,信息回不来。如果输入先被平均一遍,模型再想恢复 2Δx 尺度的小起伏,那信息已经不在输入里了,只能靠猜。

### 3.3 本项目的做法

- **训练**:保留 WRF 原生交错排布,不做平均——信息留在数据里,模型才有得学;
- **评估**:算风速、切变、矢量 RMSE 必须先有共同画布,所以要去交错——但**预测和真值套同一个算子**,被同一把低通滤一遍,比较仍然公平。

## 四、动能谱与有效分辨率(为什么 WRF 的细花纹不可信)

**缘起**:报告真值诊断第一条:"各档位动能谱在约 7 倍格距之后一致变陡……"——什么是动能谱?为什么变陡就意味着不可信?

**卡点**:按数值模式的标准口径(傅里叶分解、惯性区、数值耗散)讲,难以建立直观。

**怎么解开的**:用"低通滤波"搭桥——与去交错是同一个概念,只是主角换成了数值模式自己。

1. 风场是各种大小花纹的叠加:大花纹(几百公里的天气系统)、中花纹(几十公里的涡)、细花纹(几公里以下的抖动);如同照片 = 大轮廓 + 中细节 + 细纹理。
2. 动能谱 = 给风场做"花纹大小普查":横轴是花纹大小(左大右小),纵轴是这一档花纹的强度。大自然的规律:花纹越大越强、越细越弱,谱线平滑下滑。
3. 模拟是用格子拼出来的:比格子小的花纹画不出来;格子那么大的花纹算起来误差大,数值方法为求稳定,主动把接近格子尺度的花纹抹平(相当于模式自带一次"磨皮")。
4. 于是模式的谱在大约 7 个格子宽以下断崖式下跌——这段下跌是被抹的痕迹,不是大自然的样子。

```
 强度 │╲
      │ ╲       ← 正常区:花纹越细越弱(大自然的样子)
      │  ╲___
      │      ╲___   ← 断崖区:被模式"抹"过(不是大自然的样子)
      │          ╲__
      └───────────────→ 花纹大小(左大右小)
                 ↑
            约 7 个格子宽(折弯点)
```

**结论**:

- "变陡"以下的细花纹,强度被动过手脚,不能当真;折弯点即模式的"有效分辨率"。
- 具体数字:可信的是约 7 格距**以上**(更粗)的尺度——不是"到 7 km 为止";折弯点跟着格距走,不是固定数:四个档位(27/9/3/1 km)分别在 189/63/21/7 km 处折弯,都是各档格距的 7 倍。
- 反直觉点:格子距 1 km ≠ 细节可信到 1 km;"磨皮"从 7 个格子宽就开始了。
- 与项目的关系:超分拿 1 km 模拟当"标准答案",7 km 以下的答案自己已被抹过,不能拿它较真;能承诺、能评判的技巧应定位在有效分辨率之上。

## 五、散度与散度残差(那条"及格线"是怎么来的)

**缘起**:报告真值诊断第二条:"测定了 d04 原生网格上散度残差的量级——阶段 2 判断'散度约束有无收益空间'的标尺。" 三个词要拆:散度、残差、标尺。

**散度是什么**(先排除两个误会):

- 不是风向。风向 = 往哪吹;散度 = 风在某处"往外冒还是往里吸"的程度。全场都向东吹的风,越吹越快也有散度(拉伸);风速处处一样则散度为零——风向不变,散度可以不同。
- 不是噪声。真实大气里辐合辐散是正经物理:低压区低层辐合(往里吸)、海陆风在海岸线上交汇成辐合带、对流云底的气流汇聚。

**怎么算**:离散网格上用差分——左右界面的 u 相减、除以格距:

```
散度的一项 ≈ (右边界的 u − 左边界的 u) ÷ 格距
```

格距 1 km 时,左右两个 u 点正好相距 1 km(C 网格里 u 就存在界面上,一减一除,不用插值)。差分的本质:格子上没有"无穷小",只能用相邻格的值差代替导数——像 GPS 每 10 秒记一次位置来估瞬时车速。

**"残差"是什么**:把模式输出代回"守恒的账本"(流进流出的空气 vs 密度的变化)对账,对不平的零头就是残差。零头不可避免(差分是近似、密度靠诊断拼出、输出文件还有精度损失)——不是 WRF 的 bug,是数值世界自带的底噪。

**残差 ≠ 误差**(关键区分):

| | 需要标准答案吗 | 检查什么 |
|---|---|---|
| 误差 | 需要(所以往往拿不到) | 离真值差多远 |
| 残差 | **不需要** | 把数值代回方程,看对不平多少 |

**结论**:真值的散度残差水平约 10⁻³ s⁻¹ 量级(P95),即真值自带的散度"底噪"。用途:给模型定"及格线"——模型的散度不必为零,做到"和真值一样干净"即可。

## 六、散度约束:为什么做了又弃用

**机制**(阶段 2 的一类物理约束):训练时对模型输出场逐点算散度,按"只罚超标"的规则惩罚:

```
惩罚 = max( 0, 模型散度大小 − 真值基准水平 )    ← hinge 惩罚
不超标 → 0;超标 → 只罚超出的那一段
```

阈值取自第五节的标尺(设 0 太苛刻:真值自己都不干净;设太高等于没约束)。

**疑点**:只罚超标、不罚偏低,是单向的——结果会不会被"往低里压"?

- 逻辑上成立:对模型而言"离基准线远点"最保险,往下走没有阻力;
- 实测印证:加约束后输出散度被压低 34%、超阈值比例压低 58%(比真值还干净):

```
基准线 ────────────────   真值水平
基线模型 ≈ 贴线            ✓(和真值一样干净)
加约束后 ↓ 34%            ✗(压过头了)
```

- 为什么是毛病:目标应是"和真值一样",不是"更干净";被压掉的主要是模型每步预测里的随机噪声;代价是逐点精度退 8.6%。

**结论**:散度约束机制有效但方向过头、净收益为负,弃用(L\* = 纯 L1)。单向约束容易"压过头",是这类物理约束设计的共性坑;T0.5 的标尺正是当初判断"无收益空间"的依据。

## 七、位置偏移检查(两档场对齐吗)

**缘起**:报告真值诊断第三条:"9 km 场与 1 km 真值之间没有系统性位置偏移——两侧可直接配对,不需要位移订正。"

**在担心什么**:降尺度把两档场配对(9 km ↔ 1 km),怕的是两档的大形势**整体挪了位**(比如大风区、辐合线全图一致地偏东 5 km)——这种整场一致的错位叫"系统性位置偏移"。若有,配对就脏了:模型学的、评估比的都是错位的关系,补救要用"位移订正"(先把场平移回去再比)。

**两种"错位"先分开**:

- 技术错位:两套网格格子天然不对齐(9 km 与 1 km 的格点位置不同)——必然的、已知的,用重网格(把粗场映射到细场网格上)消掉,属常规处理,不算问题;
- 物理错位:场里的天气形势真的偏了——这才是要检查的"系统性位置偏移"。

**怎么检查**(互相关):类比两张同场景照片,把一张相对另一张来回滑动,滑到最重合处,滑动距离就是偏移量。做法:先消技术错位 → 两档都粗化到 9 km 尺度(比的是大形势)→ 扫描相对偏移,找最重合位置。结果:三个强风时刻,最重合都出现在**偏移 = 0** 处。

**结论**:

- 没有可检出的系统性位移 → 可以直接配对,不需要位移订正;
- "位移不是本档位误差的来源"——将来结果不理想,可排除这条嫌疑;
- 两档本是一次模拟的嵌套输出,大形势共享,检查把"应该一致"实测确认了一遍。

## 八、模式层监督(在哪种格式上对答案)

**缘起**:报告第四章的"模式层监督(基线)"——这是什么?为什么还有别的监督方式?

**"监督"是什么**:训练 = 模型做题、拿真值对答案、错了改。"在哪个空间监督" = **拿哪一套格式的答案去对**。

**两套格式**:

- 模式层(23 层):WRF 原生存储,像贴着地形盖的"被子",一层层堆上去(山坡处被子也起伏);
- 离地高度层(11 层):从地面往上量的"标尺"(10 m、100 m……),最终评估和交付都用它。
- 两套**不能一一对应**:"被子"上的第 5 层,在山上和平地对应的离地高度不同;换算需要插值。

**三个臂的关系**:

```
模型输出(23 层"被子"格式)
   ├──→ ① 直接对答案(逐层比)                ← 模式层监督(基线)
   └──→ 插值 ──→ 11 个"标尺"层
                └──→ ② 在对答案              ← 联合监督 = ① + ②
                                               (纯 AGL 监督 = 只有 ②)
```

- 模式层监督:只在"被子格式"里批改——训练时没人按"最终考试的格式"批改;
- 联合监督(大纲创新):接一个固定、不可学习的插值算子,让误差**同时**在两套格式上算——练习直接用考试格式批改;
- 实测:口径对齐后更好(主指标 −9.2%、切变 −20.5%)。

**结论**:模式层监督 = 最自然的做法(在模型原生格式上对答案),是四臂对比的**基线**;其余三臂(纯 AGL、低层加权、联合监督)都是相对它做改进。

## 九、双三次插值(一步到位)

**卡点**:"双三次插值"是不是"先 9→3、再 3→1"分两步?

**解开**:不是,一步到位。拆名字:"双" = 二维(横、竖两个方向都插),"三次" = 用三次多项式拟合。对每个目标点,取周围 4×4 = 16 个格点,横竖各拟合一次,一次性算出结果。

```
一步直接(实际): 9 km ──双三次插值──→ 1 km
分步(不做):     9 km ──→ 3 km ──→ 1 km
                 ↑ 每经一道再平滑一次,只会更糊
```

**为什么不分步**:插值本身是平滑操作(和"平均 = 丢细节"同类),分两步 = 平滑两遍、误差叠加;9→1 有直接对应关系,一次算完,不绕道 3 km。

**出现在**:残差输出的"底稿"(粗场插值出模糊版,网络只学差值);插值基线(不学习的对照)。

## 十、最优输入集 V\*(模型到底看什么)

**缘起**:阶段 1 的产出:"粗端 U、V 风场(23 层)+ 粗端逐层离地高度 + 粗端对数粗糙度 + cos(太阳天顶角,SZA)单通道 + 细端几何场"——五项都要解释。

| 输入 | 是什么 | 为什么给 |
|---|---|---|
| 粗端 U、V(23 层) | 9 km 风场本体 | 主料:要"加细"的原料 |
| 粗端逐层离地高度 | 每格点、每层离地面多高 | 风随高度剧变,模型要知道"这层风在多高"(同一"层号"在山谷与山顶的离地高度不同) |
| 粗端对数粗糙度(log z0) | 地表摩擦程度:海面光滑、城市/森林极糙 | 决定近地风廓线形状:同样一股高空风,地面被磨掉多少 |
| cos(SZA) 单通道 | 太阳天顶角余弦,纯天文量(可精算) | 分辨昼夜——白天湍流强、夜里近地稳定;单通道替代四通道时间编码,统计打平取最简 |
| 细端几何场 | 1 km 地形等静态信息 | 细地形是降尺度关键驱动(绕山、穿谷、海岸线拐弯);静态量、不是答案,不构成泄漏 |

**要点**:

- 五样分三类:风场本体 + 环境信息(高度、粗糙度、太阳)+ 细地形;
- 除"细端几何"外全部来自粗端——防泄漏规则的落地;细端能给的只有静态几何,细端的风场(逐时量)绝对不给(那是答案)。

## 十一、一句话总结

WRF 的风和温度错开半格存放(这就是 C 网格)。把风平均到温度点上(去交错)等于一次低通滤波,会抹掉最小的波动,而超分要学的恰恰是小尺度,所以训练阶段不做这个平均;评估时必须统一画布,就用同一个算子对预测和真值一视同仁,保证公平。

WRF 结果的可靠性还有一条尺度边界:比折弯点粗的尺度可信、更细的尺度已被数值处理抹掉,折弯点约为格距的 7 倍(1 km 档就是 7 km)。动能谱就是量这条边界的秤;超分的承诺与评判都定位在这条线以上。

散度答"风往外冒还是往里吸",散度残差是它在数值实现里对不平的零头。真值的残差水平给模型定出散度及格线——只罚超标的单向约束会压过头(散度被压低 34%、精度退 8.6%),所以散度约束被弃用。

配对之前先验证两档场没有整体挪位——没有,可以直接配对、无需位移订正。双三次插值是一步插值("双" = 二维、"三次" = 多项式),9 km 直接到 1 km。训练的"对答案格式"(模式层)与评估格式(离地高度)不同,联合监督让两者对齐。模型输入最终只有五样:粗端风场、逐层高度、粗糙度、太阳角、细地形。
