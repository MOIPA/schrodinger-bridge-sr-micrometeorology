# 昼夜分组消融实验设计

## 一、实验动机

前期消融实验得出 **地形 >> 热力 > 气压 ≈ PBLH** 的结论，但这是全天平均的结果。昼夜分组分析已发现：

- 白天：热对流活跃，W 分量 RMSE 比夜间高 40%
- 夜间：边界层稳定，模型整体表现更好

**白天和夜间的物理过程完全不同**——白天地表加热驱动对流，热力变量（辐射、热通量）理应更重要；夜间辐射冷却、地形对冷空气堆积（katabatic wind）起关键作用。直接回答：**哪些条件变量在白天重要？夜间呢？不同时段是否该给模型提供不同的条件变量？**

## 二、实验设计

### 基线配置

沿用原消融实验的轻量配置，保证 10 组实验可在合理时间内完成：

| 参数 | 值 |
|------|-----|
| 分辨率 | 128×128 |
| inner_channel | 32 |
| Loss | 纯 L2（不加 W 加权和物理约束） |
| 条件变量基数 | 10（HGT, LU, T2, TSK, SWDOWN, GLW, HFX, LH, PBLH, PSFC） |
| Epochs | 400 |
| Batch | 4 |
| 设备 | GPU |

### 消融变量设计

| 消融配置 | 去掉的变量 | 变量数 | 白天假设 | 夜间假设 |
|---------|------|:---:|---------|---------|
| **All10** | 无（全变量对照） | 10 | — | — |
| **NoTerrain** | HGT + LU_INDEX | 8 | 白天热力主导，地形影响相对弱 | **夜间地形驱动冷空气堆积，可能更重要** |
| **NoThermal** | T2 + TSK + SWDOWN + GLW + HFX + LH | 4 | **白天热力关键，去掉应显著恶化** | 夜间辐射≈0，去掉应影响较小 |
| **NoPBLH** | PBLH | 9 | 白天边界层深厚，PBLH 可能有参考价值 | 夜间边界层浅薄且稳定，PBLH 意义不大 |
| **NoPSFC** | PSFC | 9 | 气压梯度驱动白天风场，可能有用 | 夜间弱风条件下气压场作用减弱 |

### 昼夜划分

按 swdown（向下短波辐射）逐样本判定：
- **白天**：swdown > 50 W/m²
- **夜间**：swdown < 5 W/m²
- 过渡时段（5 ≤ swdown ≤ 50）排除

### 实验矩阵

共 5 × 2 = **10 组实验**：

| # | 消融 | 时段 | 实验名 |
|---|------|:---:|------|
| 1 | All10 | 白天 | `abl_day_all10` |
| 2 | All10 | 夜间 | `abl_night_all10` |
| 3 | NoTerrain | 白天 | `abl_day_noterrain` |
| 4 | NoTerrain | 夜间 | `abl_night_noterrain` |
| 5 | NoThermal | 白天 | `abl_day_nothermal` |
| 6 | NoThermal | 夜间 | `abl_night_nothermal` |
| 7 | NoPBLH | 白天 | `abl_day_nopblh` |
| 8 | NoPBLH | 夜间 | `abl_night_nopblh` |
| 9 | NoPSFC | 白天 | `abl_day_nopsfc` |
| 10 | NoPSFC | 夜间 | `abl_night_nopsfc` |

## 三、需要改动的代码

### 3.1 配置文件新增参数

```yaml
data:
  day_night_filter: "all"   # "day" | "night" | "all"
  swdown_day_threshold: 50.0   # swdown > threshold → 白天
  swdown_night_threshold: 5.0  # swdown < threshold → 夜间
```

### 3.2 数据加载器改动

在 `make_dataloaders_and_samplers` 中，数据集构建完成后按 swdown 过滤样本：

```python
# 仅保留白天/夜间样本
if day_night_filter != "all":
    swdown_idx = input_variable_names.index("swdown")
    keep_indices = []
    for i in range(len(dataset)):
        swdown_val = dataset[i]["x"][swdown_idx].mean().item()
        swdown_phys = swdown_val * scale + bias
        if day_night_filter == "day" and swdown_phys > 50:
            keep_indices.append(i)
        elif day_night_filter == "night" and swdown_phys < 5:
            keep_indices.append(i)
    dataset = Subset(dataset, keep_indices)
```

## 四、预期分析视角

实验完成后，对每个消融变量计算 **白天 − 夜间的 RMSE 差值**：

| 去除的变量 | 白天 ΔRMSE | 夜间 ΔRMSE | 昼夜差异 | 解读 |
|-----------|:--------:|:--------:|:------:|------|
| Terrain | ? | ? | ? | 差值 > 0 → 地形夜间更重要 |
| Thermal | ? | ? | ? | 差值 < 0 → 热力白天更重要 |
| PBLH | ? | ? | ? | 预期昼夜均接近 0 |
| PSFC | ? | ? | ? | 预期白天略重要 |

如果 **NoThermal 白天恶化 > 夜间恶化**，说明白天的确更需要热力变量的物理约束，为后续设计昼夜自适应模型提供依据。

## 五、评估脚本

沿用 `eval_day_night.py` 的逻辑，对每个模型分别在白天、夜间、全天测试子集上计算 RMSE/SSIM/Corr，输出汇总表。
