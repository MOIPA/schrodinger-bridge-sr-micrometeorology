# 相关工作对比

## 一、经典 PINN：直接求解 NS 方程

### 1.1 NSFnets (Jin et al., JCP 2021)

**思路**：神经网络直接学习 (t, x, y, z) → (u, v, w, p) 的映射，用 NS 方程残差作为 Loss 训练。

**VP 形式（速度-压力）**：

$$L = L_e + \alpha L_b + \beta L_i$$

| 项 | 公式 | 含义 |
|----|------|------|
| PDE 残差 | $\frac{1}{N_e}\sum_{n=1}^{N_e}\left\| \frac{\partial\mathbf{u}}{\partial t} + (\mathbf{u}\cdot\nabla)\mathbf{u} + \nabla p - \frac{1}{Re}\nabla^2\mathbf{u} \right\|^2 + \left\| \nabla\cdot\mathbf{u} \right\|^2$ | 3条动量方程 + 1条连续性方程，共4项残差 |
| 边界条件 | $\frac{1}{N_b}\sum\|\mathbf{u}^n - \mathbf{u}_b^n\|^2$ | 速度 Dirichlet 边界 |
| 初始条件 | $\frac{1}{N_i}\sum\|\mathbf{u}^n - \mathbf{u}_i^n\|^2$ | 初始时刻速度场 |

**VV 形式（涡度-速度）**：消除压力 p，输出 (u, v, w, ω_x, ω_y, ω_z)，Loss 包含 6 个 PDE 残差（3个涡度输运方程 + 3个速度 Poisson 方程）和涡度边界条件 $\|\boldsymbol{\omega}^n - \nabla\times\mathbf{u}_b^n\|^2$。

**关键特点**：
- 用自动微分计算所有导数（∂/∂t, ∂/∂x, ∂²/∂x² 等），需要网络输出对输入求二阶导
- 需要 Collocation points 覆盖整个时空域
- 不需要任何真实数据标签——纯物理驱动

### 1.2 大气风场 PINN (Cervantes & Moreles, 2024)

**思路**：从稀疏 LiDAR/站点观测重建 3D 风场。

$$L = L_{data} + \lambda_{div} L_{div}$$

$$L_{div} = \frac{1}{N}\sum_{n=1}^{N}\left\| \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} \right\|^2$$

仅约束质量守恒，没有涡度约束或动量方程。

### 1.3 扩散降尺度 (Lockwood, 2024; AirCast-SR, 2025)

**思路**：DDPM 或 Latent Consistency Model 做 LR→HR 超分。

$$L = \mathbb{E}_{t,\epsilon}\left\| \epsilon - \epsilon_\theta(x_t, t, cond) \right\|^2$$

纯数据驱动，不加入任何物理方程约束。

## 二、我们的方法

**Loss 公式**：

$$L_{total} = L_{data} + \lambda_{div} \cdot L_{3D\\_div} + \lambda_{vort} \cdot L_{vort}$$

其中：

### 2.1 数据拟合项

$$L_{data} = \frac{1}{N}\sum_{i} w_i \cdot (b_i^{true} - b_i^{est})^2$$

$w_i = 10$ (W通道), $w_i = 1$ (U/V通道)。$b^{true}$ 是 Stochastic Interpolant 框架下的真实漂移项，$b^{est}$ 是网络预测。

### 2.2 三维散度约束（连续性方程）

$$L_{3D\\_div} = \frac{1}{6}\sum_{k=0}^{5} \text{mean}\left[ \left( \frac{\partial U_k}{\partial x} + \frac{\partial V_k}{\partial y} + \frac{\partial W_k}{\partial z} \right)^2 \right]$$

水平导数用中心差分，垂直导数用层间中心差分（边界层用前向/后向差分）。

### 2.3 涡度约束

$$L_{vort} = \frac{1}{6}\sum_{k=0}^{5} \text{mean}\left[ \text{AvgPool}_4\left( \frac{\partial V_k}{\partial x} - \frac{\partial U_k}{\partial y} \right)^2 \right]$$

AvgPool₄ 提取大尺度分量（kernel=4），抑制小尺度噪声，仅约束大尺度涡度。

## 三、核心差异对比

| 维度 | NSFnets (经典 PINN) | 扩散降尺度 | **本文** |
|------|---------------------|-----------|---------|
| **训练方式** | 无数据，纯物理驱动 | 有标签，纯数据驱动 | 有标签，数据+物理联合驱动 |
| **网络输入** | (t, x, y, z) 时空坐标 | LR 风场 + 条件变量 | LR 风场 + 条件变量 + 时间 t |
| **网络输出** | (u, v, w, p) 或 (u, v, w, ω) | HR 风场 / 噪声 | 漂移项 b (18 ch) |
| **导数计算** | 自动微分（需二阶导） | 无 | 中心差分近似（无自动微分开销） |
| **物理 Loss 项数** | 4 (VP) 或 6 (VV) | 0 | **2**（散度+涡度） |
| **需要压力 p？** | 是 (VP) 或不需要 (VV) | 否 | **否** |
| **需要时序数据？** | 是（初始+边界条件） | 否 | **否** |
| **需要 Collocation points？** | 是（大量） | 否 | **否** |
| **输入/输出维度** | 逐点 | 二维图像 | **三维风场图像（18ch）** |
| **多垂直层** | 逐层或三维 | 逐变量 | **6层联合超分** |
| **W 分量不平衡处理** | 无 | 无 | **通道加权 ×10** |
| **物理约束施加对象** | 网络输出的速度场 | 无 | **网络输出的漂移场（b_est）** |

### 关键区别：为什么不能照搬 NSFnets 的公式

1. **没有 3D 气压场**：NSFnets VP 形式需要同时输出 (u, v, w, p) 并联合约束动量方程，我们只有地表 PSFC。
2. **没有时序数据**：∂u/∂t 需要连续时次，我们的数据是单时次快照。
3. **没有 Collocation points**：经典 PINN 在连续时空域采点，我们是离散网格图像，更适合有限差分。
4. **网络输出含义不同**：NSFnets 输出的是物理量（速度），我们输出的是 Stochastic Interpolant 框架中的漂移项 b，它是速度的演化方向而非速度本身。
